# 05. Phase 1 백로그 — 코어 프로토타입 (1인 개발, 6주)

목표: **"주사위 굴려 한 바퀴 도는 게 재밌는가"** 를 검증하는 플레이 가능한 빌드.
아트는 전부 임시(도형+무료 아이콘). 게임 규칙 로직(Core)은 `prototype/DiceDungeon.Core/`에 이미 구현·검증되어 있으므로, Phase 1의 실제 작업은 **Unity 프로젝트에 Core를 이식하고 Presentation(연출·UI)을 붙이는 것**이다.

## 준비 (Day 0)

- [ ] Unity 6 LTS 설치, 2D URP 템플릿으로 프로젝트 생성 (세로 1080×1920)
- [ ] Git 저장소 + Unity용 .gitignore + Git LFS 설정
- [ ] `prototype/DiceDungeon.Core/*.cs` → `Assets/_Project/Scripts/Core/`로 복사, asmdef(`DiceDungeon.Core`) 생성 — netstandard2.1이므로 수정 없이 컴파일됨
- [ ] Unity Test Runner에서 SelfTest 항목들을 EditMode 테스트로 이식

## Week 1 — 보드가 보인다

- [ ] `BoardView`: FloorGenerator 결과 24칸을 사각 트랙으로 배치 (스프라이트는 단색 사각형 + 타일 타입별 색)
- [ ] 플레이어 말(원형 토큰) 배치, 카메라 고정 프레이밍
- [ ] "굴리기" 버튼 → `DiceRoller` 호출 → 주사위 눈 UI 텍스트 표시
- [ ] 말이 눈 수만큼 칸을 따라 이동 (DOTween 칸 단위 점프, 0.15초/칸)
- **완료 기준: 버튼을 누르면 말이 보드를 돈다**

## Week 2 — 칸이 반응한다

- [ ] `TileResolver` 연동: 도착 칸 타입별 팝업/즉시 효과 (골드 획득, 함정 피해, 회복)
- [ ] 골드·HP 상단 HUD, 데미지/획득 플로팅 텍스트 (오브젝트 풀)
- [ ] 출발칸 통과 감지 → "한 바퀴!" 연출 + 보너스 골드
- **완료 기준: 전투 없이 한 바퀴 루프가 돌아간다**

## Week 3 — 전투가 붙는다

- [ ] 전투 오버레이 씬: 아군 좌 / 적 우 배치 (임시 스프라이트)
- [ ] `BattleSimulator`를 **연출 재생형**으로 구동: 시뮬레이터가 낸 결과 이벤트를 큐로 받아 순차 연출 (즉시 판정 → 연출만 재생, 03-기술설계 원칙)
- [ ] 공격/방어/포션 3버튼 수동 입력 모드 추가 (Core의 자동 정책을 입력 대기로 치환하는 `IBattleInput` 인터페이스)
- [ ] 더블=선제공격, 럭키세븐=크리 보너스 연출 표기
- **완료 기준: 전투 칸에서 이기고 지는 것이 체감된다**

## Week 4 — 런이 완성된다

- [ ] 보스 게이트 → 보스전 → 층 클리어 → "하강 or 귀환" 선택 UI
- [ ] 사망/귀환 → 런 결산 화면 (도달 층, 골드, 소울스톤)
- [ ] 층 전환 시 몬스터 스케일링 적용 확인 (Balance.cs 그대로)
- [ ] 상점 팝업: 포션/장비 구매 2슬롯
- **완료 기준: 시작 → 죽거나 귀환 → 결산까지 한 판이 끊기지 않는다**

## Week 5 — 게임처럼 느껴진다

- [ ] 주사위 3D 굴림 연출 (결과 선판정 후 스냅) — 손맛의 핵심, 하루 이상 투자 가치 있음
- [ ] 홀/짝 부적 소모품 1종 추가 (주사위 조작 재미 검증용 — Core에 이미 `RollWithParity` 있음)
- [ ] 점령 칸 시각화(깃발) + 재방문 회복 연출
- [ ] SFX 10개(주사위, 이동, 타격, 획득), 무료 에셋
- **완료 기준: 소리와 연출이 있어서 "게임" 같다**

## Week 6 — 검증한다

- [ ] Android 실기기 빌드, 프레임/발열 확인
- [ ] 지인 10명 테스트: ①한 판을 끝까지 하는가 ②"한 판 더" 하는가 ③주사위 조작 아이템을 이해하는가
- [ ] 시뮬레이터 수치와 실플레이 체감 비교 → Balance.cs 조정
- [ ] **Go/No-Go 결정**: 루프가 재미없으면 Phase 2 진입 금지, 루프를 고친다 (여기서의 피벗이 가장 싸다)
