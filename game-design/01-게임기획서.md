# 01. 게임 기획서 — 다이스 던전 (가제)

## 1. 게임 개요

| 항목 | 내용 |
|------|------|
| 제목(가제) | 다이스 던전 (Dice Dungeon) |
| 장르 | 보드 × 로그라이트 던전 RPG |
| 플랫폼 | Android / iOS (세로 화면, 원핸드) |
| 타깃 | 캐주얼~미드코어, 20~40대. 브루마블·모두의마블 경험자 + 방치형/로그라이트 유저 |
| 플레이 단위 | 1회 "탐험(런)" 15~25분. 중간 저장으로 언제든 끊고 이어하기 가능 |
| 핵심 재미 | ① 주사위 운과 아이템으로 운을 조작하는 재미 ② 칸 하나하나의 리스크/리워드 선택 ③ 런마다 다른 빌드 조합(로그라이트) ④ 런 사이의 영구 성장 |

## 2. 핵심 컨셉

**"브루마블 보드가 곧 던전이다."**

- 보드는 브루마블처럼 **한 바퀴 도는 사각형 트랙(기본 24칸)**
- 플레이어는 주사위를 굴려 이동하고, 멈춘 칸의 이벤트(전투/보물/상점/함정 등)를 처리
- **출발점을 지나 한 바퀴를 완주하면 "층 클리어"** → 보스전 → 다음 층으로 하강
- 층이 깊어질수록 몬스터가 강해지고 보상이 커짐. 사망 시 런 종료(로그라이트), 획득한 영구 재화로 메타 성장
- 브루마블의 "땅 사기"는 **"칸 점령"** 으로 변형: 정화한 전투 칸은 아군 칸이 되어, 다시 밟으면 회복/버프 제공

### 차별점 (vs 기존 게임)

- 모두의마블류: 대전 중심, 운빨 스트레스 → 본작은 **싱글 PvE 중심**, 운을 아이템·스킬로 통제하는 재미
- 랜덤 다이스/주사위 로그라이트류: 본작은 **보드 순환 + 칸 점령**이라는 브루마블 고유 구조를 유지
- Dicey Dungeons: 전투 내부가 주사위 퍼즐 → 본작은 **보드 이동이 주사위**, 전투는 가벼운 턴제 RPG

## 3. 코어 루프

```
[층 시작]
   ↓
주사위 굴림 → 칸 이동 → 칸 이벤트 처리
   ↓                        (전투 / 보물 / 상점 / 함정 / 이벤트 / 쉼터)
전투 승리 → 골드·장비·칸 점령
   ↓
한 바퀴 완주(출발칸 통과) → 보스 게이트 개방 → 보스전
   ↓
층 클리어 보상 → [다음 층] (더 강한 적, 더 좋은 보상)
   ↓
사망 or 자발적 귀환 → 런 결산 → 영구 재화(소울스톤) 획득
   ↓
[마을] 영구 성장(스탯, 캐릭터 해금, 유물) → 다음 런
```

- **분당 의사결정**: 주사위를 "언제 어떤 보조 아이템과 함께 굴릴지", 갈림길 칸에서 어느 루트로 갈지, 상점에서 무엇을 살지, 다음 층으로 내려갈지 귀환할지
- **세션 설계**: 1층 = 3~5분(한 바퀴), 1런 = 3~5층 = 15~25분

## 4. 보드 설계

### 4.1 보드 구조

- 기본 24칸 사각 트랙 (한 변 6칸). 층 테마에 따라 20/24/28칸 변형
- 5층 이상부터 **내부 십자 지름길**(리스크 높은 칸으로 구성된 단축 루트) 등장 — 갈림길에서 방향 선택 가능
- 칸 배치는 **층 생성 규칙 기반 랜덤**: 전투 45~55%, 보상 15%, 이벤트 10~15%, 함정 10%, 상점·쉼터는 층당 1~2개 보장

### 4.2 타일(칸) 종류

| 타일 | 아이콘 컨셉 | 효과 |
|------|------------|------|
| 출발(게이트) | 포탈 | 통과 시 "한 바퀴" 카운트, 보스 게이트 개방. 통과 보너스 골드 |
| 일반 전투 | 해골 | 몬스터 1~3마리와 턴제 전투. 승리 시 **칸 점령**(아군 칸 전환) |
| 정예 전투 | 붉은 해골 | 강한 적, 2배 보상 + 장비 확정 드롭 |
| 점령된 칸 | 파란 깃발 | (전투 승리한 칸) 다시 밟으면 HP 15% 회복 or 소버프. 브루마블의 "내 땅" |
| 보물 | 상자 | 골드/장비/소모품. 희귀 확률로 미믹(기습 전투) |
| 상점 | 저울 | 장비·소모품·주사위 아이템 구매. 리롤 가능(골드) |
| 쉼터(모닥불) | 모닥불 | HP 30% 회복 **또는** 스킬 강화 중 택1 |
| 함정 | 가시 | 즉발 피해/디버프. "함정 해제" 미니 선택지(민첩 스탯 판정) |
| 이벤트(?) | 물음표 | 랜덤 내러티브 이벤트, 2~3개 선택지 (리스크/리워드) |
| 도박장 | 주사위 | 골드를 걸고 홀짝/하이로우. 브루마블 황금열쇠의 변형 |
| 순간이동 | 소용돌이 | 보드의 다른 순간이동 칸으로 이동(선택) |
| 감옥(속박) | 사슬 | 1턴 정지. "탈출 주사위"(더블 필요) or 골드 지불 |
| 보스 게이트 | 왕관 문 | 한 바퀴 완주 후에만 입장 가능. 층 보스전 |

### 4.3 주사위 시스템 (핵심 차별 요소)

- 기본: 6면체 2개 (2~12 이동)
- **주사위 조작 리소스** — 운을 "통제하는" 재미의 핵심:
  - **홀수/짝수 부적**(소모품): 결과를 홀/짝으로 강제
  - **고정 주사위**(희귀): 한 개의 눈을 원하는 값으로 고정
  - **더블 보너스**: 더블이 나오면 한 번 더 굴림 + 골드 보너스 (브루마블 오마주)
  - **특수 주사위 장비**: "1이 안 나오는 주사위", "이동 후 1칸 미세조정", "짝수 눈 확률 +20%" 등 런 중 획득
- 주사위는 물리 연출(3D 굴림)로 손맛 강조, 결과는 서버/로직에서 선판정 후 연출만 동기화

## 5. 던전(층) 구성과 테마

| 층 구간 | 테마 | 특징 |
|---------|------|------|
| 1~3층 | 버려진 지하묘지 | 튜토리얼 겸 저난도, 언데드 몬스터 |
| 4~6층 | 곰팡이 동굴 | 독/중독 기믹, 함정 칸 증가 |
| 7~9층 | 용암 대장간 | 화상 기믹, 장비 강화 이벤트 다수 |
| 10~12층 | 얼어붙은 성채 | 빙결(주사위 눈 -1) 기믹 |
| 13~15층 | 심연 | 최종장, 혼합 기믹 + 최종 보스 |
| 16층~ | 무한 심연(엔드콘텐츠) | 무한 스케일링, 시즌 랭킹 |

- 각 층 클리어 시 **"하강 or 귀환"** 선택: 하강하면 보상 배율 증가, 사망 시 절반만 회수(리스크/리워드)
- 층 보스는 구간당 고유 보스 3종 로테이션, 고유 기믹(예: 3턴마다 보드 전체에 함정 살포)

## 6. 승리/패배 조건

- **런 승리**: 15층 최종 보스 처치 → 엔딩 + 상위 난이도(어센션) 해금
- **런 패배**: HP 0 → 획득 소울스톤 70% + 장비 일부만 회수
- **자발 귀환**: 층 클리어 직후 선택 시 100% 회수

## 7. 화면 구성 (세로 1080×1920)

```
┌─────────────────────────┐
│  상단바: 층수·골드·소울스톤·설정   │
├─────────────────────────┤
│                         │
│      보드 (화면 60%)      │
│   쿼터뷰 2.5D, 핀치 줌     │
│   캐릭터 말 + 타일 아이콘    │
│                         │
├─────────────────────────┤
│ 캐릭터 HP/스킬 게이지 바     │
├─────────────────────────┤
│  [소모품 슬롯×3] [주사위 굴리기]│
│        (엄지 존)          │
└─────────────────────────┘
```

- 전투 진입 시 보드가 뒤로 밀리며 전투 씬 오버레이 (사이드뷰, 아군 좌 / 적 우)
- 모든 핵심 버튼은 화면 하단 1/3 (엄지 도달 범위)에 배치
- 아트 스타일: **밝은 카툰 SD(2.5등신) + 다크 던전 배경**의 대비. 캐주얼 진입장벽↓ + 던전 분위기 유지

## 8. 튜토리얼 흐름 (첫 5분)

1. 주사위 1회 굴림 → 이동 (조작 학습)
2. 강제 전투 칸 → 자동 승리에 가까운 쉬운 전투 (전투 UI 학습)
3. 보물 칸 → 첫 장비 착용 (인벤토리 학습)
4. 함정 칸 → 피해 경험 (긴장감 학습)
5. 한 바퀴 완주 → 첫 보스(쉬움) → 층 클리어 연출 → "다음 층 or 귀환" 선택 학습
6. 첫 귀환 → 마을에서 소울스톤으로 영구 스탯 1회 강화 (메타 성장 학습)
