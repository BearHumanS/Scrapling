# 04. 개발 로드맵 · 수익화 · 리스크

## 0. 1인 개발 원칙 (전 문서 공통)

1. **아트는 AI로 생성한다** — GPT 이미지 생성으로 캐릭터/몬스터/타일/UI 제작 (파이프라인은 06 문서). 성과가 나오면 그때 외주로 교체
2. **코드보다 스코프가 리스크** — 1차 출시 범위 동결: 캐릭터 2종, 10층, 유물 12종. (기획서의 4종/15층은 라이브 확장분)
3. **서버 없는 게임** — Firebase 무료 티어로 끝나는 설계 유지. 실시간 멀티는 검토조차 하지 않음
4. **매주 빌드 가능 상태 유지** — 혼자일수록 "거의 다 됨" 상태가 길어지면 동력 상실. 매주 기기에서 돌아가는 빌드
5. **시뮬레이터로 밸런싱** — 혼자서는 플레이테스트 인력이 없으므로 `prototype/` 시뮬레이터가 QA 역할 (이미 구축됨)

## 1. 개발 로드맵 (1인 풀타임 기준 ~10개월, 부업이면 ×1.8)

### Phase 0 — 프리프로덕션 (2주)
- 엔진 셋업, 프로젝트 구조, 아트 스타일 레퍼런스 확정
- 종이 프로토타입: 실제 주사위+종이 보드로 타일 비율·한 바퀴 길이 검증 (코드보다 빠름)

### Phase 1 — 코어 프로토타입 (6주) ★ 가장 중요
- 보드 이동 + 주사위 + 타일 5종(전투/보물/상점/함정/쉼터) + 기본 턴제 전투 + 1개 층 루프
- 아트는 전부 임시(사각형+아이콘)로. **"주사위 굴려서 한 바퀴 도는 게 재밌는가"만 검증**
- 판정 기준: 본인+지인 10명이 "한 판 더" 하고 싶어 하는가. 아니면 코어 루프를 고칠 것 (여기서 피벗은 싸다)

### Phase 2 — 버티컬 슬라이스 (8주)
- 캐릭터 2종, 1~5층, 보스 1종, 실제 아트 1테마 적용, 메타 성장(유물 10종), 세이브
- 이 시점에 스크린샷/GIF가 "게임처럼" 보여야 함 (스토어 페이지·커뮤니티 반응 테스트 가능)

### Phase 3 — 콘텐츠 확장 (10주)
- **1인 출시 범위**: 캐릭터 2종, 10층(3테마), 보스 3종, 유물 12종, 이벤트 20종, 튜토리얼, 사운드
- (캐릭터 4종·15층·이벤트 30종은 라이브 시즌 확장분으로 이월)
- 광고/IAP/분석 SDK 연동, 치트·시뮬레이션 기반 밸런싱

### Phase 4 — 소프트론칭 (6주)
- 1~2개국(필리핀/캐나다 등) 또는 국내 사전예약 없이 조용히 출시
- 핵심 지표 검증: D1 리텐션 35%+, D7 12%+, 튜토리얼 완주 70%+, 평균 세션 15분+
- 지표 미달 시 확장 대신 개선 반복

### Phase 5 — 정식 출시 + 라이브 (이후 상시)
- 시즌제(8주): 신규 캐릭터 or 테마층 + 배틀패스 + 밸런스 패치
- 지표 검증 후: 일일 던전 랭킹 → 길드/친구 → (장기) 실시간 대전 검토

## 2. 수익화 (BM)

### 원칙
- **Pay-to-Win 금지**: 전투력 직결 상품 없음. 로그라이트는 실력·빌드 게임성이 곧 상품 가치
- 수익 축: **보상형 광고 40% + 배틀패스 35% + 캐릭터/스킨 25%** (목표 비중)

### 상품 설계

| 상품 | 가격대 | 내용 |
|------|--------|------|
| 보상형 광고 | 무료 | 런 결산 소울스톤 ×1.5, 사망 시 1회 이어하기, 일일 상점 리롤 |
| 광고 제거 | ₩5,900 (1회) | 보상형 광고의 보상은 자동 수령으로 전환 (혜택 유지, 시청만 제거) — 만족도 최상 상품 |
| 배틀패스 | ₩9,900 / 시즌(8주) | 무료 트랙 + 유료 트랙(스킨, 소울스톤, 다이아). 진행은 플레이로만 |
| 캐릭터 팩 | ₩7,900 | 신규 캐릭터 즉시 해금 (플레이로도 해금 가능 — 시간 단축 상품) |
| 스킨/주사위 스킨 | ₩3,900~ | 순수 치장. 주사위 스킨은 매 턴 보이는 아이템이라 구매 동기 높음 |
| 초보자 팩 | ₩3,300 (1회) | 소울스톤+유물 티켓, 가성비 앵커 상품 |

### 금지 사항
- 확률형 장비/캐릭터 뽑기(가챠) 도입 금지 — 국내 확률 공시 규제 부담 + 로그라이트 게임성 훼손
- 스태미나(플레이 제한) 금지 — 세션 기반 로그라이트와 상극

## 3. KPI 목표 (소프트론칭 기준)

| 지표 | 목표 |
|------|------|
| D1 / D7 / D30 리텐션 | 35% / 12% / 5% |
| 튜토리얼(첫 런 귀환) 완주율 | 70% |
| 평균 세션 길이 / DAU당 세션 | 15분 / 2.5회 |
| 광고 시청률 (노출 대비) | 60% |
| 결제 전환율 | 2% |

## 4. 리스크 분석

| 리스크 | 가능성 | 대응 |
|--------|--------|------|
| **코어 루프가 재미없음** (주사위 이동이 단순 반복으로 느껴짐) | 높음 | Phase 1에서 아트 없이 검증. 주사위 조작 아이템·갈림길·리스크 선택지를 초반부터 투입해 "결정" 밀도 확보 |
| 브루마블 요소가 껍데기화 (그냥 로그라이트가 됨) | 중간 | 칸 점령, 완주 보너스, 더블, 도박장 등 브루마블 고유 재미를 시스템에 계속 연결 (02 문서의 보드-전투 연동) |
| 1인 개발 스코프 폭발 | 높음 | 멀티·길드·실시간 요소는 전부 후순위 고정. 캐릭터 4종·15층으로 1차 출시 범위 동결 |
| 아트 리소스 부족 | 중간 | SD 카툰 스타일은 외주 단가가 낮고 에셋 스토어 보완 가능. 테마 재활용(팔레트 스왑) 설계 |
| 밸런스 붕괴 | 중간 | 시드 기반 1,000런 자동 시뮬레이션(03 문서)으로 층별 사망률 상시 측정 |
| 유사 게임 (모두의마블 IP, 주사위 로그라이트) 과의 차별화 실패 | 중간 | "칸 점령 + 층 하강"의 조합은 두 장르 어디에도 없음 — 스토어 소개·첫 GIF에서 이 장면을 전면에 |
| 플랫폼 심의/규제 | 낮음 | 가챠 없음 + 도박장은 게임 내 재화만 사용 (사행성 이슈 회피), 자체등급분류 12세 목표 |
