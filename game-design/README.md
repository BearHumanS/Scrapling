## 한 줄 요약

> **"주사위를 굴려 던전 보드를 돌고, 멈춘 칸에서 몬스터와 싸우며, 한 바퀴 돌 때마다 더 깊은 층으로 내려가는 로그라이트 보드 RPG"**

## 핵심 결정 사항 (TL;DR)

- **엔진: Unity 6 (2D URP) 확정** — 1인 개발 기준: 에셋 스토어가 아트를, 성숙한 광고/IAP SDK가 수익화 공수를 대체 (상세 비교는 00 문서 참고)
- **개발 체제: 1인 개발, 예산 10만원** — 출시 스코프 동결(캐릭터 2종·10층), 밸런싱은 시뮬레이터(`prototype/`)로 자동화
- **아트: GPT 이미지 생성 + Unity 2D Animation(무료) 본 리깅** — 풀 리깅은 플레이어 2종+보스 3종만, 잡몹은 코드 연출 (06 문서)
- **플랫폼: iOS·Android 동시 출시** (Apple 개발자 계정 보유)
- **장르**: 싱글 중심 로그라이트 보드 RPG + 비동기 PvP(시즌 랭킹)는 후순위
- **세션 길이**: 한 판(1회 런) 15~25분, 한 바퀴(1층) 3~5분
- **BM**: 광고(보상형) + 배틀패스 + 캐릭터/스킨 — 확률형 장비 뽑기는 지양
- **타깃**: 캐주얼~미드코어, 세로 화면(원핸드 플레이)
