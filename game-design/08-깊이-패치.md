# 08. 깊이 패치 (v5) — 플레이테스트 피드백 대응

첫 플레이테스트 피드백: **"재미는 있는데 깊이가 부족하다."**
진단: 시스템 수는 충분(스탯·전직·트리·속성)하나 **분당 의사결정 밀도**가 낮았다. 주사위는 구경거리였고, 전투 최적해는 자명했으며, 이벤트에 선택이 없었다. v5는 시스템 추가가 아니라 **결정 지점 추가**다.

## 1. 소모품 — 보드를 결정 공간으로

| 소모품 | 효과 | 만드는 결정 |
|--------|------|------------|
| 홀짝 부적 | 이번 굴림의 합을 홀/짝으로 강제 | "6칸 앞 쉼터에 가고 싶다 → 짝수 부적" |
| 폭탄 | 전투 개시 시 적 전체 25+층×8 피해 | 정예/보스전에 아껴 쓸까, 지금 쓸까 |
| 연막탄 | 전투 1회 회피 (보상·점령 없음) | 빈사 상태에서 도망 vs 도박 |

- 획득: 보물 상자 25%, 이벤트 보상, 상점 판매 (부적 25+층×8 골드)
- 첫 런부터 부적 1개 지급 — 조작의 재미를 즉시 경험
- 시뮬레이션 정책: HP 50% 미만이면 사거리(2~12) 내 쉼터/내 땅의 거리 홀짝에 부적 사용

## 2. 이벤트 선택지 — 스탯의 전투 외 용도

이벤트 8종(본편 30종의 대표 유형), 각 2~3 선택지, **스탯 판정** 도입:

- 판정 확률 = 50% ± (스탯-난이도)×4.5%p, 25~95% 클램프
- 예: "잠긴 보물상자" → 자물쇠 따기(**재주**, 성공 장비/실패 함정) vs 부수기(**힘**, 소액 골드) vs 포기
- 재주·운·힘·체력·지능이 전투 밖에서 쓰이므로 **스탯 배분이 전투력 최적화 문제가 아니게 됨**
- 마법사 패시브 재정의: 실패한 판정 1회 재굴림

## 3. 몬스터 트레이트 — "누굴 먼저 잡지?"

3층부터 일반 몬스터 35% 확률 (이름으로 노출):

| 트레이트 | 효과 | 대응 결정 |
|----------|------|----------|
| 치유사 | 동료 HP 60%↓면 공격 대신 12% 회복 | **먼저 처치** (자동 정책도 우선 타겟) |
| 광폭 | HP 50%↓에서 공격 ×1.4 | 빨리 끝내거나 기절 봉쇄 |
| 장갑 | 첫 2회 피격 절반 | 도트·광역이 유리 |
| 맹독 | 공격마다 플레이어 중독 | 장기전 금지 |
| 폭발 | 사망 시 공격력 ×1.5 피해 | 잡는 순서·타이밍 |

- 10층+ 보스는 광폭화 고정
- 플레이어도 이제 중독에 걸린다 (플레이어 측 상태이상 틱 구현)

## 4. 콤보 시너지 — 스킬 순서에 의미

- **빙결 → 크리**: 빙결된 대상 크리티컬 +25%p (빙결탄 → 마력 폭발 콤보)
- **인화**: 화상 5중첩 도달 시 폭발 — 중첩×6 즉발 + 화상 제거 (화염구/발화로 쌓아 터뜨리기)

## 6. 남은 깊이 후보 (다음 패치)

- 장비 옵션 다양화 (접두사/접미사), 세트 효과
