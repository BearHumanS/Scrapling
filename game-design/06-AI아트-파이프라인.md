# 06. AI 아트 + 애니메이션 파이프라인 (예산 10만원 체제)

원칙: **이미지는 GPT로 생성하고, 움직임은 무료 도구(본 리깅 + 코드 연출)로 만든다.**
AI는 "완성된 스프라이트 시트"를 못 만든다 — 프레임 간 일관성이 깨진다. 그래서 프레임 애니메이션이 아니라 **한 장을 파츠로 쪼개 뼈대로 움직이는 스켈레탈 방식**으로 간다.

## 1. 전체 파이프라인

```
① GPT 이미지 생성 (파츠 분리를 전제로 한 프롬프트)
② Photopea(무료 웹)에서 파츠 레이어 분리 → PSB 저장
③ Unity PSD Importer로 임포트 (레이어가 자동으로 스프라이트 분리됨)
④ Unity 2D Animation 패키지로 본(Bone) 리깅 + 웨이트
⑤ 애니메이션 클립 제작 (idle / attack / hit / death — 캐릭터당 4개)
⑥ 나머지 연출은 DOTween 코드로 (이동, 흔들림, 스쿼시&스트레치)
```

### 도구 선택

| 용도 | 도구 | 비용 |
|------|------|------|
| 스켈레탈 애니메이션 | **Unity 2D Animation + PSD Importer** (공식 패키지) | 무료 |
| 대안 (외부 툴 선호 시) | DragonBones (오픈소스), Blender 그리스펜슬 | 무료 |
| 파츠 분리·보정 | Photopea (웹, PSD 호환), Krita | 무료 |
| 이펙트 | Unity 파티클 + 무료 이펙트 에셋 | 무료 |

- Spine이 업계 표준이지만 유료($99+)라 제외. Unity 2D Animation이 같은 개념(본·웨이트·IK)을 무료로 제공하고, 엔진 내장이라 왕복 공수도 없음
- 프레임 애니메이션이 꼭 필요한 곳(이펙트, 주사위)은 AI가 아니라 파티클/3D로 해결

## 2. 스타일 고정 (일관성이 생명)

AI 아트의 최대 리스크는 그림체 불일치. 순서를 지킬 것:

1. **스타일 앵커 1장을 먼저 확정** — 대표 캐릭터 1종을 수십 번 생성해 마음에 드는 1장을 "공식 그림체"로 선언
2. 이후 모든 프롬프트에 **동일한 스타일 문단**을 복사해 붙이고, 앵커 이미지를 참조로 첨부 (GPT 이미지 편집/참조 기능 활용)
3. 색은 생성 후 **고정 팔레트로 보정** (Photopea에서 그라데이션 맵) — 팔레트 통일이 그림체 차이를 절반은 가려줌
4. 생성물은 `스타일가이드.md`에 프롬프트와 함께 기록 (재현 가능하게)

### 스타일 문단 템플릿 (모든 프롬프트에 고정 첨부)

```
2.5등신 SD 카툰 스타일, 두꺼운 다크브라운 외곽선, 셀 셰이딩 2단계,
채도 높은 메인 컬러 + 어두운 던전 배경과 대비, 모바일 게임 스프라이트,
단색 배경(후처리 제거용), 정면 3/4 뷰
```

### 파츠 분리용 캐릭터 프롬프트 템플릿

```
[스타일 문단] + 기사 캐릭터, 팔다리를 몸통에서 살짝 벌린 A-포즈,
머리/몸통/왼팔/오른팔/왼다리/오른다리/무기가 겹치지 않게,
관절 부위는 둥글게 마감 (스켈레탈 리깅용 게임 캐릭터 원화)
```

- 한 번에 안 나오면: 전신 1장을 뽑은 뒤 "이 캐릭터의 오른팔만 따로, 같은 스타일로" 식으로 부위별 재생성
- 겹침 부위(어깨 뒤 등)는 Photopea에서 클론 스탬프로 몇 분 메꾸면 됨

## 3. 필요 에셋 목록 (출시 스코프 기준)

| 분류 | 수량 | 애니메이션 |
|------|------|-----------|
| 플레이어 캐릭터 | 2종 × 파츠 분리 | 리깅 4클립 (idle/attack/hit/death) |
| 몬스터 | 12종 | **리깅 없이** idle은 코드 숨쉬기(스케일 트윈), 피격은 흔들림+플래시 |
| 보스 | 3종 × 파츠 분리 | 리깅 4클립 (보스만 풀 리깅 — 투자 대비 효과 큰 곳) |
| 타일 아이콘 | 13종 | 정지 + 반짝임 트윈 |
| 배경 | 3테마 × 2장 (보드/전투) | 패럴랙스만 |
| UI (프레임·버튼·아이콘) | 1세트 | 트윈 |
| 주사위 | 3D 모델 (Unity 기본 큐브 + AI 생성 눈 텍스처) | 물리 굴림 |
| 스토어 키아트·아이콘 | 3장 | — |

핵심: **풀 리깅은 플레이어 2종 + 보스 3종 = 5개만.** 잡몹 12종까지 리깅하면 혼자서는 일정이 터진다. 잡몹은 코드 연출(트윈)로 충분히 살아있어 보임 — Slay the Spire도 잡몹은 거의 정지 이미지다.

## 4. Unity 2D Animation 작업 순서 (캐릭터 1종 기준, 숙련 후 반나절)

1. Package Manager에서 `2D Animation` + `PSD Importer` 설치
2. 파츠 분리된 `.psb` 파일을 프로젝트에 드롭 → 자동으로 레이어별 스프라이트 + 프리팹 생성
3. Skinning Editor에서 본 생성 (몸통→팔→무기 계층), 지오메트리 자동 생성 후 웨이트 확인
4. Animation 창에서 클립 4개 제작:
   - **idle**: 몸통 상하 3px + 호흡 회전 1도, 2초 루프
   - **attack**: 무기 팔 스윙 0.3초 (임팩트 프레임에 이벤트 → 데미지 연출 동기화)
   - **hit**: 뒤로 젖힘 + 흰색 플래시 0.2초
   - **death**: 회전하며 페이드 0.5초
5. Animator Controller는 단순 트리거 4개 — 상태머신 복잡하게 만들지 말 것

## 5. 법적·스토어 유의사항

- Google Play·App Store 모두 AI 생성 아트 사용 자체는 제한 없음 (2026 현재). 단 **타 IP 유사성 주의** — "브루마블", "모두의마블" 명칭·트레이드 드레스 사용 금지, 프롬프트에 특정 게임/작가 스타일 지칭 금지
- OpenAI 생성물은 상업적 이용 가능 (이용약관상 소유권 사용자 귀속). 생성 프롬프트·날짜 기록을 남겨둘 것
- 폰트·사운드는 라이선스 표기 파일(`CREDITS.md`)을 게임 설정 화면에 연결
