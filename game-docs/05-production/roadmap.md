## 1. 단계 개요

```
Prototype → Vertical Slice → MVP / Early Access → 정식 출시(1.0) → 출시 후(멀티)
```

> 기간은 팀 규모·가용시간에 따라 조정되는 **상대적 가이드**다. 본격 상업 팀 기준
> 잠정치이며, 실제 일정은 가용 인력 확정 후 재산정한다.

## 2. 마일스톤 상세

### M0. Prototype (코어 검증) — 약 1~2개월
- **목표**: "보드+전투" 코어 루프가 재미있는지 검증.
- **산출물**: 회색박스 보드 1바퀴, 주사위·이동·땅 구매, 전투 1종, AI 1종.
- **완료 기준(DoD)**: 한 판이 처음부터 끝까지 플레이 가능, 핵심 재미 내부 확인.

### M1. Vertical Slice (재미·비주얼 증명) — 약 2~3개월
- **목표**: 최종 품질의 1구역을 완성해 "이 게임의 느낌"을 증명.
- **산출물**: 완성도 높은 보드 1구역 + 전투 + 도트 아트 + 사운드 + UX, 클래스 1~2종.
- **DoD**: 외부에 보여줄 수 있는 수직 슬라이스, (가능 시) Steam 페이지 준비 착수.

### M2. MVP / Early Access — 약 3~5개월
- **목표**: 시장 검증 가능한 최소 완성 + Steam 얼리 액세스(선택).
- **산출물**: 메인 스토리 1막, 클래스 다수, 메타 성장, 다수 칸/이벤트, 세이브,
  한/영 현지화, 옵션·도전과제.
- **DoD**: 안정적 빌드, EA 기준 콘텐츠 분량 충족, 위시리스트 캠페인 가동.

### M3. 정식 출시 1.0 — 약 3~6개월(EA 후)
- **목표**: 콘텐츠·밸런스 완성.
- **산출물**: 전체 막/맵, 밸런스 튜닝, 추가 클래스/콘텐츠, 버그 안정화, 다국어 확대.
- **DoD**: KPI 기준 충족(리뷰·안정성), 마케팅 정점, 1.0 출시.

### M4. 출시 후 / 멀티플레이 — 출시 이후
- **목표**: 수명 연장.
- **산출물**: 온라인 멀티플레이([multiplayer-plan](../03-technical/multiplayer-plan.md)),
  추가 맵·모드·콘텐츠.
- **DoD**: 멀티 베타 → 정식, 라이브 운영 안정.

## 3. 마일스톤별 검증 게이트

| 게이트 | 질문 | 통과 못하면 |
|--------|------|------------|
| 프로토타입 후 | "코어가 재미있나?" | 재설계/피벗 |
| 슬라이스 후 | "비주얼·완성도가 통하나?" | 아트/UX 보강 |
| MVP/EA 후 | "시장이 반응하나?(위시리스트/리뷰)" | 콘텐츠·마케팅 재조정 |
| 1.0 전 | "안정성·밸런스 OK?" | 출시 연기 |

## 4. 병렬 트랙

- **기획**: 시스템·콘텐츠·밸런스 데이터.
- **개발**: 코어 → 시스템 → 콘텐츠 → 멀티.
- **아트**: 스타일 확정 → 슬라이스 → 양산.
- **비즈니스**: Steam 페이지 → 위시리스트 → 데모/페스티벌 → 출시 마케팅.

## 5. 결정 사항 (Decisions) — v0.2

- ✅ **얼리 액세스 채택**: M2(MVP)를 EA로 출시, 피드백·매출 후 M3(1.0).
