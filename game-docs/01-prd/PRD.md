## 1. 제품 개요

- **제품명(가제)**: 다이스마블 (DiceMarble)
- **장르**: 부루마블식 보드 × RPG × 로그라이트
- **플랫폼**: PC(Windows 우선, macOS/Linux 검토) / 유통: Steam
- **엔진**: Godot 4.x
- **한 줄 정의**: 주사위로 보드를 돌며 땅을 사고, 칸마다 전투·모험으로 영웅을
  키우는 도트 보드 RPG.

## 2. 제품 비전 & 목표

**비전**: "익숙한 보드게임의 재미 위에 RPG의 성장과 서사를 얹어, 혼자서도
친구와도 몇 번이고 다시 하고 싶은 도트 보드 RPG를 만든다."

**제품 목표**
- 한 판 20~40분의 명확하고 반복 가능한 코어 루프 완성
- 빌드 다양성과 메타 성장으로 높은 리플레이성 확보
- 도트 비주얼·UX로 인디 시장에서 또렷한 정체성 확립
- 싱글 출시로 시장 검증 후 멀티플레이로 수명 연장

## 3. 성공 지표 (KPI)

| 단계 | 지표 | 목표(예시·조정 가능) |
|------|------|---------------------|
| 출시 전 | Steam 위시리스트 | 정식 출시 시점 10,000+ |
| 출시 직후 | 첫 달 판매량 | 5,000+ |
| 품질 | Steam 리뷰 | "매우 긍정적"(80%+) |
| 몰입 | D1 / D7 리텐션 | D1 35%+, D7 12%+ |
| 세션 | 평균 플레이타임 | 누적 5시간+ / 유저 |

> 수치는 인디 벤치마크 기반 잠정값. 데모/얼리액세스 데이터로 재보정.

## 4. 타깃 시장 & 페르소나

- **시장**: PC 인디, 보드/캐주얼 전략 + 로그라이트 RPG 교차 수요층
- **페르소나 A "추억의 보드러"**: 부루마블/모두의마블 향수, 가벼운 한 판 선호
- **페르소나 B "빌드 장인"**: Slay the Spire류 로그라이트 빌드업·리플레이 선호
- **페르소나 C "같이 놀 친구"**: 친구와 와글와글 멀티(후속 단계 타깃)

## 5. 범위 (Scope)

### In Scope (1차 — 싱글 출시, 얼리 액세스로 진입)
- 싱글플레이(AI 상대) 보드 RPG 코어 루프
- 보드 시스템(땅 구매·건물·통행료·이벤트 칸)
- 턴제 전투, 캐릭터 클래스/스킬, 장비·인벤토리
- 경제·육성 + **하이브리드 구조(캠페인 + 로그라이트)** 공용 메타 성장
- 메인 스토리 1막(캠페인) + 로그라이트 런 + 사이드 이벤트
- 도트 아트·사운드, 세이브/로드, 한국어/영어 현지화

### Out of Scope (후속/제외)
- 온라인 멀티플레이 (→ 2차 단계, [multiplayer-plan](../03-technical/multiplayer-plan.md))
- 모바일/콘솔 포팅 (출시 후 검토)
- 레벨 에디터/모드 지원, 시즌제 라이브서비스
- 실시간(논턴제) 전투

## 6. 기능 요구사항 (MoSCoW)

| 우선순위 | 기능 |
|----------|------|
| **Must** | 주사위·이동·보드, 땅 구매/통행료, 턴제 전투, 캐릭터 1+클래스, 세이브/로드, AI 상대, 메인 스토리 1막 |
| **Should** | 다중 클래스, 스킬트리, 장비/인벤토리, 메타 성장, 다국어, 난이도 옵션, 도전과제 |
| **Could** | 추가 보드맵, 이벤트/카드 다양화, 보스 러시 모드, 컬렉션/도감 |
| **Won't (이번엔)** | 온라인 멀티, 모드 지원, 실시간 전투, 모바일 |

## 7. 비기능 요구사항 (NFR)

- **성능**: 중급 PC에서 60fps, 로딩 5초 이내(목표)
- **저장**: 자동 저장 + 수동 슬롯, 데이터 손상 방지(임시파일→교체)
- **현지화**: 텍스트 외부화(번역키), 한국어/영어 1차, 폰트 다국어 대응
- **접근성**: 키/패드 입력, 색약 고려 팔레트, 텍스트 크기 옵션(가능 범위)
- **안정성**: 크래시 리포트 수집(옵트인), 결정적 로직(멀티 대비)
- **빌드/배포**: 재현 가능한 빌드 파이프라인, Steam 빌드 자동 업로드

## 8. 릴리스 단계

| 단계 | 목표 | 산출물 |
|------|------|--------|
| **Prototype** | 코어 루프 검증 | 보드 1바퀴 + 전투 1종, 회색박스 |
| **Vertical Slice** | 재미·비주얼 증명 | 완성도 높은 1구역(보드+전투+아트+사운드) |
| **MVP / Early Access** | 시장 검증 | 스토리 1막, 클래스 다수, 메타 성장, Steam EA |
| **정식 출시 (1.0)** | 완성 | 전 콘텐츠, 다국어, 밸런스 완료 |
| **출시 후 (Post-1.0)** | 수명 연장 | 멀티플레이, 추가 콘텐츠/맵 |

> 세부 일정·완료 기준은 [roadmap](../05-production/roadmap.md) 참조.

## 9. 가정 · 제약 · 의존성

- **가정**: 소규모 본격 팀, 도트 아트 자체 제작/외주 병행 가능
- **제약**: 예산·인력 한정 → MVP 우선, 멀티는 후속으로 분리
- **의존성**: Godot 4.x LTS, Steamworks SDK, GodotSteam 등 서드파티 안정성
