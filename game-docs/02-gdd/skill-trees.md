## 1. 설계 원칙

- **3갈래 구조**: 각 클래스는 **3개 분기**(전투/유틸/경제 또는 클래스별 변형)로
  나뉜 트리. 빌드 정체성을 명확히.
- **선택과 포기**: 한 런에서 모든 노드 습득 불가 → 분기 특화 유도.
- **액티브 + 패시브 혼합**: 분기마다 핵심 액티브 1~2 + 보조 패시브.
- **보드 연계**: 일부 노드는 전투 밖(주사위/통행료/영지)에 작용 → 장르 정체성.
- **포인트 획득**: 레벨업 시 스킬 포인트(SP) 1, 일부는 메타/이벤트로 추가.

## 2. 공통 트리 규칙

```
티어1(요구 Lv1) → 티어2(Lv3) → 티어3(Lv6) → 정점(Lv10, 분기당 1택)
```
- 상위 티어는 하위 노드 선행 필요(가지치기). 정점 노드는 분기 색채를 결정.

## 3. 전사 (Warrior) — "굳건한 영주"

| 분기 | 컨셉 | 핵심 노드(예) |
|------|------|----------------|
| **A. 격돌(공격)** | 근접 화력 | T1 강타 강화 / T2 연속 베기(2회) / T3 처형(저HP 적 추가피해) / 정점 **광란(체력↓ATK↑)** |
| **B. 수호(방어)** | 탱킹·반사 | T1 방패올리기+ / T2 가시 갑옷(반사) / T3 도발+자가회복 / 정점 **불굴(치명 1회 방어)** |
| **C. 영주(경제)** | 자산↔전투력 | T1 통행료 +10% / T2 영지 1개당 DEF+ / T3 성 보유 시 광역 버프 / 정점 **군세(영지 수=아군 강화)** |

## 4. 마법사 (Mage) — "확률의 주문사"

| 분기 | 컨셉 | 핵심 노드(예) |
|------|------|----------------|
| **A. 원소(화력)** | 광역·연소 | T1 화염구+ / T2 연쇄 번개 / T3 화상 폭발 / 정점 **메테오(대광역)** |
| **B. 빙결(제어)** | 상태이상 | T1 빙결+ / T2 둔화 확산 / T3 빙결 적 추가피해 / 정점 **절대영도(전체 빙결)** |
| **C. 점술(유틸/주사위)** | 확률 조작 | T1 이벤트 보상+ / T2 주사위 1회 리롤 / T3 LUCK 스케일 피해 / 정점 **운명왜곡(주사위 눈 지정)** |

## 5. 도적/상인 (Rogue·Merchant) — "발 빠른 장사꾼"

| 분기 | 컨셉 | 핵심 노드(예) |
|------|------|----------------|
| **A. 암습(공격)** | 치명·선공 | T1 급습+ / T2 출혈 / T3 약점 간파(치명률↑) / 정점 **그림자 일격(선공 즉사 확률)** |
| **B. 교란(유틸)** | 회피·도주 | T1 회피+ / T2 연막(적중↓) / T3 무조건 도주 / 정점 **분신(1회 완전 회피)** |
| **C. 상술(경제)** | 골드·주사위 | T1 골드 획득+15% / T2 상점 할인 / T3 골드→피해 전환 / 정점 **황금손(골드로 스탯 환산)** |

## 6. 빌드 예시 (가이드)

| 빌드 | 조합 | 플레이 스타일 |
|------|------|----------------|
| 광전사 전사 | 전사 A 집중 | 고위험 고화력, 빠른 전투 |
| 요새 영주 | 전사 B+C | 탱킹+자산으로 장기전 |
| 화염 폭격 마법사 | 마법사 A | 광역 섬멸 |
| 운명술사 | 마법사 C + LUCK 장비 | 주사위·확률로 보드/전투 조작 |
| 황금 도적 | 도적 C + 상점 빌드 | 경제로 압도(골드=파워) |

## 7. 메타 연계

- 메타 강화로 **시작 SP** / 특정 정점 노드 **사전 해금** 가능([content-tables](content-tables.md) §8).
- 캠페인/로그라이트 공용 — 해금된 노드는 양 모드에서 사용.

## 8. 데이터 스키마 (요약)

```
SkillData:
  id, class, branch(A/B/C), tier(1~3/정점),
  type(active/passive), cost(EN), prereq[], effects[],
  board_effect(optional)  # 주사위/통행료/영지 등 전투 외 효과
```
