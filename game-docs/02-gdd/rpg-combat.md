## 1. 캐릭터 & 클래스

- **플레이어 캐릭터**: 보드 위의 "말"이자 RPG의 영웅.
- **클래스(1차 출시 3종 권장)**:

| 클래스 | 컨셉 | 특징 |
|--------|------|------|
| **전사(Warrior)** | 근접 탱커/딜러 | 높은 HP·방어, 안정적 |
| **마법사(Mage)** | 광역·상태이상 | 낮은 HP, 강한 스킬 화력 |
| **상인/도적(Rogue·Merchant)** | 경제 특화 | 골드·통행료·주사위 조작 강점 |

> 클래스마다 **보드 플레이 스타일**(전투형 vs 경제형)이 달라 빌드 다양성 확보.

## 2. 스탯 (Stats)

| 스탯 | 설명 |
|------|------|
| **HP** | 생명력, 0이면 전투 패배/사망 |
| **공격력(ATK)** | 기본 피해량 |
| **방어력(DEF)** | 받는 피해 감소 |
| **속도(SPD)** | 턴 순서/회피 영향 |
| **행운(LUCK)** | 치명타·주사위·드랍률 영향 |
| **마나/기력** | 스킬 사용 자원 |

- 스탯 = 레벨 성장 + 장비 + 영지 버프(부루마블 자산 연계)의 합.

## 3. 전투 방식 — 옵션 비교 & 권장안

| 옵션 | 장점 | 단점 |
|------|------|------|
| **A. 클래식 턴제(JRPG식)** | 전략 깊이, 스킬 연출 | 진행 느려질 수 있음 |
| **B. 주사위 기반 턴제** | 보드 테마 일관성, 운+전략 | 밸런스 난이도↑ |
| **C. 오토배틀 + 개입** | 빠른 진행, 보드 흐름 유지 | 조작감 약함 |

> **권장안: A(클래식 턴제)를 기본으로, 주사위 굴림을 전투에도 일부 도입(B 가미).**
> 보드 테마를 살리면서 전략 깊이를 확보. 진행 속도는 "전투 속도/스킵" 옵션으로 보완.

## 4. 턴제 전투 흐름

```
전투 진입(전투 칸/보스) → 턴 순서 결정(SPD)
→ 플레이어 행동(공격/스킬/아이템/방어/도주)
→ 적 행동 → 상태이상·버프 정산 → 승패 판정
→ 보상(골드·경험치·드랍) / 패배 시 사망 처리
```

- **행동 종류**: 일반공격, 스킬(자원 소모), 아이템, 방어, 도주(확률).
- **상태이상**: 중독·기절·화상·둔화 등(데이터 정의, 확장 용이).

## 5. 스킬 & 스킬 트리

- 클래스별 스킬 세트 + 레벨/메타로 해금되는 스킬 트리.
- 액티브 스킬(전투 사용) + 패시브(상시 효과, 보드 효과 포함).
- 빌드: "전투 특화 / 경제 특화 / 주사위 특화" 등 방향성 분기.

## 6. 몬스터 & 보스

- **일반 몬스터**: 전투 칸에서 출현, 보드 진행도/구역별 난이도 스케일.
- **엘리트**: 강화 몬스터, 희귀 드랍.
- **보스**: 챕터 관문, 고유 패턴/기믹, 핵심 보상·해금.
- 데이터(`EnemyData`, `EncounterData`)로 정의 → 밸런싱·추가 용이.

## 7. 장비 & 인벤토리

- **장비 슬롯(예)**: 무기, 방어구, 장신구, 주사위(특수).
- **희귀도**: 일반/고급/희귀/영웅/전설 — 색상 코드로 도트 UI 표현.
- **제작/강화**: 영지 수확 소재로 장비 제작·강화([economy-progression](economy-progression.md)).
- **인벤토리**: 제한 슬롯(전략적 선택), 정렬/필터, 판매.

## 8. 사망 / 부활

- **사망**: HP 0 → 부활 자원 있으면 부활, 없으면 런 종료(로그라이트) 또는
  거점 귀환 페널티(캠페인).
- 모드별 사망 처리 정책은 GDD 모드 정의와 연동.
