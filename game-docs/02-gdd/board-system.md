## 1. 보드 구성

- **형태**: 정사각형 순환 경로(부루마블식). 1차 출시 맵 1~3종.
- **칸 수(예시)**: 한 변 7칸 × 4변 = 약 28~40칸 (밸런스에 따라 조정).
- **분기/지름길**: 일부 맵에 지름길·포탈로 변주(후속 확장 여지).

## 2. 칸 종류

| 칸 | 설명 | RPG 재해석 |
|----|------|-----------|
| **땅(영지)** | 구매 가능, 건물 건설, 통행료 징수 | 영지 = 자산 + 캐릭터 버프 원천 |
| **전투 칸** | 몬스터 출현, 턴제 전투 발생 | 던전 입구 |
| **보스 칸** | 강력한 보스전, 큰 보상 | 챕터 관문 |
| **상점 칸** | 장비·소모품·스킬 구매 | 마을 상인 |
| **보물 칸** | 골드·아이템·랜덤 보상 | 보물상자 |
| **이벤트 칸** | 랜덤 텍스트 이벤트(선택지) | 분기 사건 |
| **함정 칸** | 피해/디버프/골드 손실 | 위험 지대 |
| **출발 칸(START)** | 한 바퀴 시 골드·경험치 보너스 | 거점 귀환 |
| **감옥/정체 칸** | 일정 턴 정지 또는 탈출 조건 | 포로/속박 |
| **순간이동 칸** | 무작위/지정 칸으로 이동 | 마법진 |
| **휴식/회복 칸** | HP/자원 회복 | 모닥불 |

> 칸 종류·비율은 데이터(Resource)로 정의해 맵별로 손쉽게 구성/조정.

## 3. 주사위 & 이동

- **기본**: 주사위 1~2개(1~6), 합산만큼 전진.
- **변형 주사위**(육성/아이템으로 해금): 가중 주사위, 리롤, 선택 이동(±1),
  특정 칸 호밍 등 → 빌드 다양성.
- **이동 처리**: 시작칸→경로 따라 한 칸씩 애니메이션, 도착칸 이벤트 트리거.
- **통과 효과**: 일부 칸은 "통과"만 해도 효과(예: 출발칸 보너스).

## 4. 땅 / 건물 / 통행료 (부루마블식 + RPG)

- **구매**: 빈 땅 도착 시 골드로 구매. 같은 색 세트 보유 시 시너지.
- **건물(업그레이드)**: 단계별 건설(예: 막사→요새→성)로 통행료·버프 상승.
- **통행료**: 상대(또는 AI) 영지 도착 시 통행료 지불.
- **RPG 연결**:
  - 영지 보유/세트가 **캐릭터 스탯·스킬 버프**로 환산(예: 성 보유 시 방어력↑).
  - 영지에서 자원(골드/소재) 주기 수확 → 장비 제작/강화에 사용.
  - 영지 점령전: 전투로 상대 영지 탈취 가능(대전/멀티 핵심 재미).

## 5. 턴 진행 규칙

```
턴 시작 → (상태이상/영지수입 정산) → 주사위 → 이동 → 칸 이벤트
→ 행동(구매/건설/전투/상점/스킵) → 턴 종료 → 다음 플레이어
```

- **더블(같은 눈)**: 1회 추가 이동(부루마블식). 연속 더블 제한(감옥行 등).
- **행동 페이즈**: 이동 후 영지 관리·인벤토리 사용 등 부가 행동 허용.

## 6. AI 상대 (싱글)

- 난이도별 AI: 구매/건설/전투 선택의 휴리스틱(자산 효율, 위험 회피).
- 멀티 전환 대비, AI도 동일 룰·인터페이스로 행동(결정적 로직 권장).
  → [architecture](../03-technical/architecture.md), [multiplayer-plan](../03-technical/multiplayer-plan.md)

## 7. 데이터 모델 (요약)

- `BoardData`: 칸 배열, 맵 메타.
- `TileData`(Resource): 칸 종류, 파라미터(가격/적/이벤트ID/보상 등).
- `EventData` / `EncounterData`: 이벤트·전투 정의.
