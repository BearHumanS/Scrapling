## 1. 재화 (Currencies)

| 재화 | 획득 | 용도 |
|------|------|------|
| **골드(Gold)** | 통행료·전투·보물·영지 수입 | 땅 구매·건설·장비 구매 |
| **경험치(EXP)** | 전투·퀘스트·출발칸 통과 | 레벨업 → 스탯·스킬 |
| **소재(Materials)** | 영지 수확·드랍 | 장비 제작·강화 |
| **메타 재화(가칭 "정수")** | 판 종료 보상 | 영구 강화·해금(런 간 유지) |

> 골드·EXP·소재는 **판 내(run-scoped)**, 메타 재화는 **판 간(meta-scoped)**.

## 2. 성장 축 (Progression Axes)

1. **레벨 성장(판 내)**: EXP → 레벨업 → 스탯·스킬 포인트.
2. **자산 성장(판 내)**: 땅·건물 → 골드 수입 + 스탯 버프.
3. **장비 성장(판 내)**: 구매·드랍·제작·강화.
4. **메타 성장(판 간)**: 영구 강화·신규 클래스/아이템/주사위 해금.

## 3. 자산 ↔ 전투력 연결 (핵심 디자인)

부루마블식 자산을 단순 점수가 아니라 **캐릭터 강함으로 환산**한다.

- **영지 세트 보너스**: 같은 구역 점유 → 스탯/스킬 버프(예: +ATK%).
- **건물 단계 효과**: 건물 등급↑ → 통행료↑ + 고유 버프(예: 성=DEF, 시장=골드).
- **수입 → 재투자 루프**: 영지 수입(골드/소재) → 장비/강화 → 전투력 → 더 깊은
  보드 공략 → 더 좋은 영지.
- **밸런스 원칙**: "경제 빌드"와 "전투 빌드"가 서로 다른 경로로 비슷한
  파워 커브에 도달하도록 설계.

## 4. 성장 곡선 (예시 가이드)

- **레벨 EXP**: 완만한 지수 곡선(`needEXP = base * level^1.5` 등, 튜닝값).
- **적 난이도**: 보드 진행도/구역 인덱스에 비례 스케일.
- **골드 인플레이션 관리**: 후반 골드 싱크(고급 건설·강화·상점 가격)로 흡수.
- **목표**: 한 판 내 "약함→강함" 체감, 매 바퀴 의미 있는 성장 1개 이상.

## 5. 보상 설계

- **즉시 보상**: 골드·EXP·아이템(칸/전투 직후 피드백).
- **누적 보상**: 영지·세트·도감·도전과제.
- **판 종료 보상**: 성과(깊이/자산/격파)에 비례한 메타 재화.
- **랜덤성 통제**: 드랍은 가중 테이블 + 보호장치(연속 꽝 방지)로 체감 개선.

## 6. 난이도 & 모드 밸런스

- **난이도 옵션**: 쉬움/보통/어려움(+ 로그라이트 상승 난이도 단계).
- **AI 난이도**: 구매/건설/전투 휴리스틱 강도 조절.
- **밸런스 작업 방식**: 데이터(Resource/CSV) 기반 수치 → 스프레드시트로 튜닝 →
  플레이테스트 지표로 반복 보정.

## 7. 이코노미 안전장치

- 파산/무한루프 방지(통행료 상한, 음수 자산 한계, 강제 매각).
- 메타 강화의 파워 인플레 통제(해금형 위주, 상시 스탯 증가는 완만하게).
