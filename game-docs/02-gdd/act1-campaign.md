## 1. 1막 개요

| 항목 | 내용 |
|------|------|
| 제목(가) | **"출발선의 모험가"** |
| 무대 | 첫 번째 보드 대륙 — **새싹 마을 ~ 도박꾼 고원** |
| 목표 | 보드를 공략하며 성장 → 1막 보스 **주사위 기사** 격파 |
| 분량(목표) | 플레이 약 40~60분(튜토리얼 포함), 보드 2바퀴+ 진행 |
| 핵심 학습 | 주사위·이동·땅 구매·통행료·전투·상점·메타 강화 |
| 클래스 | 전사/마법사/도적 중 택1 ([content-tables](content-tables.md)) |

| B2 | 튜토리얼 보드 | 명랑 | 짧은 1바퀴로 주사위·이동·구매·통행료 학습. 슬라임 첫 전투. |

## 3. 1막 보드 구성 (구역 2단계)

```
[1구역: 새싹 마을]  ── 온보딩, 쉬운 적, 첫 영지
        │ (한 바퀴 후 고원 게이트 개방)
[2구역: 도박꾼 고원] ── 엘리트·도박 이벤트·보스 칸
```

- **칸 비율(예)**: [content-tables](content-tables.md) "28칸 맵 예시" 기반,
  2구역은 전투·함정·이벤트 비중↑.
- **게이트**: 1구역에서 일정 조건(레벨/자산/한 바퀴 완료) 충족 시 2구역 개방.

## 4. 주요 NPC & 대사 샘플 (혼합 톤)

> 대사는 번역키로 외부화. 아래는 분위기 참고용 샘플.

**딜러 (가이드)** — 명랑, 능청
- (튜토리얼) "자, 주사위를 굴려보라구. 운명? 그런 건 굴려봐야 아는 거야!"
- (보스 직전) "…고원 너머는 농담이 안 통해. 진심으로 가라구, 모험가."

**마블 상회 점주** — 명랑, 장사꾼
- "골드는 돌고 도는 거야~ 일단 사고 보면 다 쓸데가 있다니까?"

**주사위 기사 (보스)** — 긴장, 위압
- (등장) "굴려진 주사위는 멈추지 않는다. ……네 운명도 이미 정해졌다."
- (페이즈 전환) "운이 좋군. 하지만 운은 곧 바닥난다."

## 5. 이벤트 스크립트 (분기·결과)

> 형식: 제목 / 트리거 / 본문 / 선택지 → 결과. 데이터는 `EventData`로 구현.

### EVT-A1-01 · 수상한 상인 (명랑)
- **트리거**: 1구역 이벤트 칸
- **본문**: "후드를 쓴 상인이 반짝이는 상자를 내민다. '싸게 줄게, 정말로.'"
- **선택지**:
  - ① 산다(골드 −50) → 70% 고급 아이템 / 30% 빈 상자(꽝)
  - ② 흥정한다(LUCK 판정) → 성공 시 −30에 구매 / 실패 시 상인 떠남
  - ③ 무시 → 효과 없음

### EVT-A1-02 · 도박장 (명랑+긴장)
- **트리거**: 2구역 이벤트 칸
- **본문**: "고원의 도박장. 주사위 한 판에 인생이 갈린다… 던질래?"
- **선택지**:
  - ① 베팅(골드 −100) → 주사위 굴림: 합 7+ 시 골드 +250 / 미만 시 손실
  - ② 큰 베팅(골드 −300) → 성공 시 +800 / 실패 시 전액 손실 + 디버프
  - ③ 떠난다 → 효과 없음

### EVT-A1-03 · 갈림길의 기사 (긴장)
- **트리거**: 2구역, B5 전후
- **본문**: "부상당한 기사가 길을 막는다. '주사위 기사의 부하다… 도와주겠나, 아니면?'"
- **선택지**:
  - ① 돕는다 → 전투(고블린 무리) → 승리 시 보스전 버프 + 보상
  - ② 외면한다 → 골드 소량 획득, 단 보스전서 적 강화
  - ③ 회유(도적/상인 특성 시) → 전투 없이 정보+아이템

### EVT-A1-04 · 저주받은 신단 (긴장)
- **트리거**: 2구역 함정/이벤트 칸
- **본문**: "낡은 신단이 희미하게 빛난다. 손을 대면… 축복일까, 저주일까."
- **선택지**:
  - ① 기도(랜덤) → 50% 강력 버프 / 50% 디버프(다음 전투까지)
  - ② 파괴 → 소재 획득, 신성 페널티 없음
  - ③ 떠난다 → 효과 없음

## 6. 보스전 — 주사위 기사 (3페이즈)

> 데이터: `boss_dice_knight` ([content-tables](content-tables.md)).

| 페이즈 | HP 구간 | 기믹 | 의도 |
|--------|---------|------|------|
| P1 | 100~67% | 기본 공격 + "운명의 일격"(주사위 눈만큼 피해) | 패턴 학습 |
| P2 | 66~34% | 보드 칸 일부 봉인(이동 제약), 광역기 추가 | 압박·자원관리 |
| P3 | 33~0% | "최후의 굴림"(고위력 카운트다운), 디버프 폭주 | 클라이맥스 |

- **공략 힌트**: P3 카운트다운은 기절/둔화로 지연 가능 → 스킬·아이템 사전 비축.
- **연출**: 페이즈 전환 시 화면 톤 다운(긴장), 사운드 레이어 추가
  ([sound-design](../04-art/sound-design.md)), 대사 B6.
- **보상**: 보스 장비 1종, 메타 재화(정수) 대량, **2막/신규 콘텐츠 해금**.

## 7. 튜토리얼 통합 (B1~B2)

- **단계적 노출**: 주사위 → 이동 → 구매 → 통행료 → 전투 → 상점 순으로
  필요할 때 1개씩 안내(과부하 방지).
- **스킵 옵션**: 숙련자용 튜토리얼 스킵 제공.
- **안전 구간**: 튜토리얼 보드에선 사망/파산 없이 학습.

## 8. 캠페인 ↔ 로그라이트 연결

- 1막에서 등장한 적·이벤트·아이템은 **로그라이트 풀에 편입**(재사용).
- 1막 클리어 시 로그라이트용 시작 보너스/난이도 단계 해금.
- 공용 메타 강화(정수)는 양 모드에서 함께 누적([content-tables](content-tables.md) §8).
