## 2. 핵심 스탯 정의

| 스탯 | 효과(예시 공식) |
|------|----------------|
| HP | 0이면 사망. 최대치 = 기본 + 레벨성장 + 장비 + 영지버프 |
| ATK | 기본 피해 = ATK × 스킬계수 − 적 DEF |
| DEF | 받는 피해 감소(감산 또는 비율, 튜닝) |
| SPD | 전투 턴 순서 결정, 회피율 일부 |
| LUCK | 치명타율·드랍률·주사위 보정 |
| 기력(EN) | 스킬 사용 자원, 매 턴 회복 |
