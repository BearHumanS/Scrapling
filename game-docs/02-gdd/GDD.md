## 1. 디자인 한 줄 요약

부루마블식 보드 위를 주사위로 돌며, 도착한 칸에서 전투·상점·이벤트를 겪고,
땅·장비·레벨로 영웅을 키워 보드의 목표를 달성하는 **턴제 보드 RPG**.

## 2. 디자인 기둥 (Design Pillars)

1. **"한 칸 한 칸이 설렌다"** — 모든 칸이 의미 있는 선택/사건이 되도록.
2. **"쉽지만 깊다"** — 주사위처럼 직관적이되 빌드·전략의 깊이를 제공.
3. **"다시 하고 싶다"** — 로그라이트 메타 성장과 빌드 다양성으로 리플레이성.
4. **"보고만 있어도 즐겁다"** — 도트 비주얼·연출·사운드의 만족감.

## 3. 게임 루프

### 3.1 코어 루프 (한 턴)
```
주사위 굴리기 → 말 이동 → 도착 칸 이벤트 처리
   (땅 구매 / 통행료 / 전투 / 상점 / 보물 / 함정 / 스토리)
→ 결과 정산(골드·경험치·아이템) → 다음 플레이어 턴
```

### 3.2 게임 루프 (한 판)
```
캐릭터/맵 선택 → 여러 바퀴 진행(턴 반복)
→ 보드 목표 달성 또는 보스 격파 → 승패 판정 → 보상/정산
```

### 3.3 메타 루프 (판과 판 사이)
```
한 판 종료 → 메타 재화 획득 → 영구 강화·신규 클래스/아이템 해금
→ 다음 판 난이도/빌드 선택 → 반복
```

> 자세한 칸/전투/경제 규칙은 하위 문서 참조.

## 4. 승리 / 패배 조건

- **승리(예시안)**: ① 최종 보스 격파, ② 목표 자산/명성 달성, ③ 마지막 생존
  중 모드별로 채택. (모드별 조건은 아래 5장)
- **패배**: 캐릭터 사망(HP 0) & 부활 자원 소진, 또는 파산(자산 음수 한계 초과).

## 5. 게임 모드

| 모드 | 설명 | 단계 |
|------|------|------|
| **캠페인 / 스토리** | 스토리를 따라 보드를 공략, 보스 격파가 목표(누적 진행) | 1차 출시 |
| **로그라이트 런** | 무작위 보드·이벤트로 빌드 쌓아 최대 깊이 도전(런 단위) | 1차 출시 |
| **싱글 vs AI 보드전** | 부루마블식 대전(파산시키기) + RPG 요소 | 1차 출시 |
| **온라인 멀티** | 친구/온라인 유저와 보드전 | 후속 단계 |

> **하이브리드 구조(확정)**: 캠페인과 로그라이트를 **병행 제공**하며, 두 모드가
> **공용 메타 성장(영구 강화·해금)** 을 공유한다. 캠페인으로 서사·온보딩을,
> 로그라이트로 리플레이성을 담당해 서로를 보완한다.
> 공용 시스템은 [content-tables](content-tables.md)(메타 강화)·
> [economy-progression](economy-progression.md) 참조.

## 6. 핵심 시스템 개요 (상세는 하위 문서)

- **보드 시스템** → [board-system](board-system.md): 칸 종류, 주사위·이동,
  땅 구매·건물·통행료, 이벤트 칸.
- **전투/RPG** → [rpg-combat](rpg-combat.md): 클래스·스탯·스킬, 턴제 전투,
  몬스터·보스, 장비·인벤토리.
- **경제/육성** → [economy-progression](economy-progression.md): 재화, 레벨·성장,
  자산↔전투력 연결, 밸런스·난이도.
- **서사** → [narrative](narrative.md): 세계관, 캐릭터, 퀘스트, 보드-스토리 연결.

## 7. 플레이어 흐름 (첫 30분 경험)

1. 인트로 컷신(도트) → 캐릭터/클래스 선택
2. 튜토리얼 보드(짧은 1바퀴): 주사위·이동·땅 구매·간단 전투 학습
3. 첫 보스 또는 첫 스토리 분기 → 보상·해금
4. 메타 화면에서 첫 영구 강화 → "다음 판" 유도

## 8. UX / 화면 구성 (개략)

- **보드 뷰**: 보드·말·칸 정보, 주사위 버튼, 자산/상태 HUD
- **전투 뷰**: 캐릭터·적·스킬바·턴 순서
- **메뉴/메타**: 캐릭터 시트, 인벤토리, 상점, 메타 강화 트리, 도감
- **연출**: 주사위/이동/전투 타격감, 보상 획득 피드백 중시
