## 1. 개요

침공 = **내 영웅이 상대 보드에 직접 진입**해 상대가 깔아둔 **트랩·수비 유닛**을 뚫고
**코어(본진)** 를 공략하는 페이즈. 파밍으로 키운 전력이 여기서 소비·검증된다.

- **공격자(나)**: 영웅 + 파밍으로 편성한 병력/장비/소모품.
- **수비자(상대/AI)**: 보드에 배치한 **트랩** + **수비 유닛** + **코어 HP**.
- **승리**: 상대 코어 HP를 0으로 → 침공 성공(약탈·보상). **패배**: 영웅 전멸/후퇴.

## 2. 침공 진입 & 진행 (턴제 침투)

```
침공 창 개방(라운드 마일스톤 or 능동 개시)
 → 상대 보드의 "입구"에서 시작, 코어를 향해 경로 진행
 → 각 칸에서: 트랩 발동 판정 / 수비 유닛 조우 시 전투 / 통과
 → 코어 도달 → 코어 방어전 → 승패 정산
```

- **경로**: 상대 보드의 순환 경로를 입구→코어 방향으로 침투(코어는 상대 START/왕성 등 지정 칸).
- **정보**: 상대 보드는 일부만 공개(정찰로 트랩 위치 파악 여지) → 심리전.
- **자원 소모**: 침공 중 영웅 HP·소모품 소모 → **무리한 침공은 리스크**.

## 3. 트랩 시스템

파밍으로 얻은 트랩을 **내 보드가 아니라 상대 보드에 심는다**(공격적 견제)
또는 **내 보드 수비용**으로도 배치(양용). M0.5는 수비 배치부터.

| 트랩 | 효과(초안) | 카운터플레이 |
|------|-----------|--------------|
| 가시덫 | 통과 영웅 HP 피해 | 정찰로 위치 확인·해제, 우회 |
| 함정굴 | 1턴 이동 정지(둔화) | 탈출 스킬, 이동 버프 |
| 독무 | 침공 동안 지속 피해(중독) | 해독·정화, 속전속결 |
| 경보진 | 수비 유닛 강화·소집 | 은신·기습, 빠른 코어 직행 |
| 골드덫 | 침공 실패 시 자원 일부 강탈 | 보험, 확실할 때만 침공 |

- **원칙**: 모든 트랩엔 **반격 수단** 존재(즉사·복구불능 금지) → feel-bad 방지.
- **밀도 제한**: 트랩 슬롯 상한(보드 크기·티어 비례) → 도배 방지.

## 4. 수비 유닛 & 코어

- **수비 유닛**: 파밍으로 편성, 특정 칸/코어 주변에 배치. 침공 영웅과 전투.
- **코어(본진)**: 상대의 심장부. HP 보유, 코어 주변 수비가 최후 방어선.
- **수비 설계 = 파밍형의 강점**: 개발/자원이 많을수록 트랩·유닛·코어가 두꺼움
  → [round-tempo-system](round-tempo-system.md) "빠름=초반 취약"과 직결.

## 5. 전투 규칙 (조우/코어전)

- 기본은 [rpg-combat](rpg-combat.md) 턴제 전투 재사용(공격/스킬/방어).
- 피해 공식은 [balance-design](balance-design.md) §4 (비율 감산) 공용.
- 조우 전투: 영웅(+동행 병력) vs 수비 유닛. 승리 시 진행, 패배 시 후퇴.
- 코어전: 코어 HP + 주변 수비 동시 상대(가장 어려운 관문).

## 6. 승패 & 보상

| 결과 | 공격자 | 수비자 |
|------|--------|--------|
| 침공 성공(코어 격파) | 약탈(자원/메타 재화), 라운드 우위 | 자원 일부 손실, 보드 일시 약화 |
| 침공 실패(후퇴/전멸) | 영웅 부상·소모품 손실, 골드덫 피해 | 방어 성공 보상, 명성 |

- **캐치업**: 뒤처진 쪽의 침공 성공 시 추가 보상(격차 보정).
- **회복**: 침공 후 양측 일정 라운드 재정비(연속 침공 남용 방지).

## 7. 싱글 / 멀티

- **싱글**: 내가 AI 보드 침공 / AI가 내 보드 침공(교대). 캠페인 보스는 강한 보드.
- **멀티(후속)**: 실시간 1:1 침공전, 또는 **비동기**(상대 방어 스냅샷에 침공).

## 8. 데이터 스키마 (요약)

```
TrapData:  id, name_key, effect(type,value,duration), counter_hint, slot_cost, tier_req
DefenderData: id, unit_ref(EnemyData/UnitData), placement(tile/core), count
CoreData:  hp, tier_scaling, guard_slots
InvasionResult: success(bool), attacker_losses, loot, defender_losses
```

## 9. 프로토타입(M0.5) 최소 반영

- 트랩 **1~2종**(가시덫·함정굴), 수비 유닛 1종, 코어 HP.
- 침공 = 입구→코어 3~5칸 침투, 칸마다 트랩/조우 1회, 코어전 1회.
- "빠르게 돌아 티어만 높고 수비 얇은" AI를 조기 침공하면 이득 → **초반 취약 검증**.
