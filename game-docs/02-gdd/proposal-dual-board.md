## 1. 배경 / 문제의식

현재 코어는 **공유 보드(부루마블식)** — 모두 한 판을 돌며 남의 땅에 통행료를 낸다.
장점은 친숙함이지만, "남의 땅을 밟는 불운"처럼 **수동적이고 통제 불가한 운** 요소가
로그라이트 빌드업 재미와 다소 충돌한다.

**대안**: 진영마다 **자기 보드**를 갖고, 보드를 **파밍(개발)** 해 전력을 키운 뒤 **전투**하고,
**상대 보드에 트랩/방해를 심는** 방식. → 능동성·전략성이 커지고 "자산=전투력" 기둥이 강화된다.

## 2. 개념 요약

> **"내 보드를 굴려 키우고(farm), 키운 전력으로 싸우고(fight), 상대 보드를 방해한다(sabotage)."**

- 각 플레이어(진영)는 **독립된 보드**를 소유.
- 주사위·이동·땅·건물은 유지하되 **"공유 땅 구매" → "내 영토 개발"** 로 재해석.
- 파밍으로 자원·유닛·영웅 강화·**트랩**을 확보.
- 주기적으로 전투 페이즈 → 승패로 메타 재화·해금.

## 3. 현재(공유 보드) vs 제안(개별 보드)

| 항목 | 공유 보드(현행) | 개별 보드(제안) |
|------|-----------------|-----------------|
| 보드 | 1개 공유 | 진영마다 1개 |
| 핵심 행동 | 통행료·자산 경쟁(수동) | 내 엔진 구축(능동) |
| 운 요소 | "남 땅 밟는 불운" 큼 | 운은 파밍에 한정, 불쾌감↓ |
| 상호작용 | 통행료·점령 | 전투 + 트랩/방해 |
| USP "자산=전투력" | 간접 | **직접·강함** |
| 부루마블 향수 | 강함 | 약함(재해석) |
| UI 복잡도 | 낮음 | 보드 2개 → 높음 |
| 로그라이트 궁합 | 보통 | 매우 좋음 |

## 4. 코어 루프(제안)

```
[파밍 페이즈] 내 보드에서 주사위·이동 → 타일 개발/자원 수확/유닛·영웅 강화 → 트랩 설치
        ↓ (N턴 또는 조건 충족)
[전투 페이즈] 내 전력 ↔ 상대 → 내가 심은 트랩이 상대 보드/전투에서 발동
        ↓
[정산·메타] 승패 보상, 영구 강화·해금 → 다음 라운드
```

- **파밍 타일(예)**: 자원지(골드/소재), 병영(유닛), 대장간(장비), 제단(스킬), 함정공방(트랩), 성장(영웅 스탯).
- **템포**: "몇 턴 파밍 → 1회 전투" 리듬. 라운드가 갈수록 파밍 산출·적/상대 강도 상승.

## 5. 전투·방해 상호작용 — 4형식 비교 (핵심)

> 척도: ◎매우좋음 / ○좋음 / △보통 / ▽약함.

| 형식 | 조작감 | 긴장감 | 관전재미 | 구현난이도 | 싱글적합 | 멀티적합 | 밸런스 |
|------|--------|--------|----------|------------|----------|----------|--------|
| **A. 침공형** (내 영웅이 상대 보드 진입, 수비·트랩 돌파) | ◎ | ◎ | ○ | △(어려움) | ◎ | ○ | △ |
| **B. 오토배틀형** (키운 유닛/영웅 자동 전투, TFT류) | △ | ○ | ◎ | ○ | ○ | ◎ | △ |
| **C. 공성/웨이브형** (상대에 몬스터 웨이브, 내 보드는 트랩 방어=타워디펜스) | ○ | ◎ | ○ | △ | ◎ | ○ | ▽ |
| **D. 원격 견제형** (파밍 위주 + 이벤트로 트랩·재해 심기, 최종 결전만 직접) | △ | △ | △ | ◎(쉬움) | ○ | ◎(비동기) | ○ |

### 형식별 상세

**A. 침공형 (추천)**
- 내 영웅이 상대 보드에 직접 들어가 상대가 심은 트랩·수비 유닛을 뚫고 본진(코어) 공략.
- 트랩이 "진입 경로의 위협"으로 자연스럽게 기능 → **트랩 심기의 의미가 가장 큼**.
- 능동적·서사적("적진 침투"). RPG 전투와 결합 최적.
- 리스크: 침공/수비 양방향 밸런스·구현 복잡. 턴제로 풀면 완화 가능.

**B. 오토배틀형**
- 각자 보드에서 키운 유닛·영웅을 배치 → 자동 전투. 트랩은 상대 유닛 약화/편성 교란.
- 파밍(빌드) → 전투가 깔끔히 분리. **관전·리플레이·멀티(특히 다인전) 최적**.
- 리스크: 직접 조작감 약함. RPG "내가 싸운다" 손맛과는 거리.

**C. 공성/웨이브형**
- 상대에게 몬스터 웨이브를 파견, 내 보드는 트랩·수비로 막는 **타워디펜스형 상호 공방**.
- 트랩/방어 빌드가 주역 → "상대 보드 방해" 아이디어와 직결.
- 리스크: 밸런스 까다로움(공/수 비대칭), RPG 육성과 결이 다소 다름.

**D. 원격 견제형**
- 대부분 파밍, 상호작용은 이벤트/카드로 상대 보드에 트랩·재해를 심는 간접 견제. 최종만 직접 결전.
- **구현 가장 쉬움, 비동기 멀티 최적**(친구 보드에 하루 한 번 방해 등).
- 리스크: 상호작용이 미지근해 긴장감·즉각 재미 약함.

### 권장안
- **A. 침공형을 코어로**, **B/D의 요소를 부분 차용**하는 하이브리드 제안:
  - 기본 전투 = **침공형(턴제 RPG)** — 손맛·서사·트랩 의미 극대화.
  - 다인전/비동기 멀티 = **오토배틀·원격견제 요소**로 확장(후속).
- 이유: 우리 정체성(RPG 육성 + 도트 + 하이브리드)과 가장 잘 맞고, 트랩 아이디어가
  가장 살아나는 형식이 침공형이기 때문.

## 6. 트랩 / 방해 시스템 (개념)

| 유형 | 예시 | 카운터플레이 |
|------|------|--------------|
| 경로 트랩 | 가시·함정칸(침공 영웅 피해/둔화) | 정찰·해제 스킬, 우회 |
| 자원 방해 | 상대 수확량 감소, 골드 도난 | 방어 건물, 보험 |
| 편성 교란 | 상대 유닛 디버프/봉인 | 정화·예비 유닛 |
| 재해 | 일정 턴 보드 일부 봉쇄 | 복구 행동, 대비 이벤트 |

- **원칙**: 모든 방해엔 **반격 수단**이 있어야 "feel-bad" 방지. 방해는 지연·손해지
  즉사·복구불능이 아니어야 함.

## 7. 싱글 / 멀티 적용

- **싱글**: 내 보드 파밍 → **AI 보드 침공/방어**. 캠페인은 보스 진영의 보드를 공략.
- **멀티(후속)**: 실시간 1:1 침공전, 또는 **비동기**(친구 보드 파밍·방해를 두고 겨룸).
- 하이브리드(캠페인+로그라이트) 구조와 그대로 호환. → [GDD](GDD.md)

## 9. 장단점 종합

**장점**: 능동성·전략성↑, 불쾌한 운↓, "자산=전투력" 강화, 트랩=심리전, 로그라이트/비동기 궁합.
**단점**: 부루마블 향수 약화, UI/구현 복잡도↑, 파밍↔전투 페이싱·트랩 밸런스 난이도.
