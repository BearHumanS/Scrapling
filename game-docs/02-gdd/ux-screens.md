## 1. 화면 흐름도 (Screen Flow)

```
[부팅/스플래시]
   │
[메인 메뉴] ── 옵션 ── 도감/업적 ── 종료
   │
   ├─▶ [캠페인] ─▶ 세이브 슬롯 선택 ─▶ (이어하기/새 게임)
   ├─▶ [로그라이트 런] ─▶ 클래스/시작 보너스 선택
   ├─▶ [메타 강화] ─▶ 영구 강화·해금 트리
   └─▶ [vs AI 보드전] ─▶ 룰/AI 난이도 설정
                 │
                 ▼
            [보드 화면] ◀──────────┐
                 │ (칸 도착 이벤트) │
     ┌───────────┼───────────┐    │
     ▼           ▼           ▼    │
 [전투 화면] [상점 화면] [이벤트 팝업] ┘
     │           │           │
     └───────────┴───────────┘
                 ▼
            [결과/정산] ─▶ [메타 화면] ─▶ 다음 판/메뉴
```

## 2. 보드 화면 (핵심)

```
┌──────────────────────────────────────────────┐
│ [HP ❤80/120] [💰1,250G] [Lv.4 ▮▮▮▱]    [⚙메뉴]│  ← 상단 HUD
│                                                │
│        ┌───┬───┬───┬───┬───┬───┬───┐          │
│        │출 │땅 │전 │땅 │상 │보 │땅 │          │
│        ├───┘   └───┴───┴───┴───┘   ├          │
│        │땅                       전 │          │
│        │전        [🎲 보드]        땅 │  ← 보드  │
│        │땅                       이 │          │
│        ├───┐   ┌───┬───┬───┬───┐   ├          │
│        │보 │땅 │휴 │땅 │함 │보스│땅 │          │
│        └───┴───┴───┴───┴───┴───┴───┘          │
│                                                │
│  [🎲 주사위 굴리기]   [🎒인벤] [🏰영지] [📜퀘스트]│  ← 액션바
└──────────────────────────────────────────────┘
```
- **상단 HUD**: HP/골드/레벨·경험치/메뉴.
- **중앙**: 순환 보드, 내 말·상대 말, 칸 종류 아이콘.
- **하단 액션바**: 주사위(주행동), 인벤토리/영지/퀘스트(부가행동).
- **칸 도착 시**: 해당 칸 패널(구매/통행료/전투 진입 등) 팝업.

## 3. 전투 화면

```
┌──────────────────────────────────────────────┐
│  적: 주사위 기사  [HP ▮▮▮▮▮▮▱▱ 240/320]        │
│           👹                                    │
│                          (피격 이펙트/연출)      │
│   🦸 플레이어                                    │
│  [HP ❤72/120] [EN ⚡3/5]                        │
│ ┌────────────────────────────────────────────┐│
│ │ [공격] [강타2] [방패1] [아이템] [방어] [도주] ││ ← 스킬바
│ └────────────────────────────────────────────┘│
│  턴 순서: 🦸 ▶ 👹 ▶ 🦸 …            [⏩배속]    │
└──────────────────────────────────────────────┘
```
- 스킬 비용(EN) 표기, 사용 불가 시 비활성.
- 배속/스킵 옵션으로 진행 속도 보완([rpg-combat](rpg-combat.md) 권장안).

## 4. 상점 / 인벤토리 / 영지

- **상점**: 좌측 판매 목록(아이콘·가격·툴팁), 우측 보유 골드·구매 확인.
- **인벤토리**: 그리드 슬롯, 장비 슬롯(무기/방어구/장신구/주사위), 비교 툴팁, 정렬/판매.
- **영지 관리**: 보유 영지 목록·건물 단계·세트 보너스·수입 표시, 건설/업그레이드 버튼.

## 5. 메타 강화 화면

```
[메타 재화: 정수 ✦ 420]
┌─ 강화 트리 ──────────────────────────┐
│  강인함(HP+10) ──▶ 강철의지(HP+25)     │
│  종잣돈(골드+50) ──▶ 투자(이자 수입)    │
│  [마법사 해금] [운명조작(리롤+1)]       │
└──────────────────────────────────────┘
```
- 캠페인/로그라이트 공유 진행(하이브리드). 해금형 위주로 파워 인플레 통제.

## 6. 핵심 UX 원칙

1. **한 화면, 한 핵심 행동**: 매 순간 "다음에 뭘 할지" 명확.
2. **피드백 우선**: 주사위·이동·타격·보상에 즉각적 시청각 반응(juice).
3. **정보 계층화**: 요약은 HUD, 상세는 툴팁/패널(클릭·호버).
4. **빠른 진행 옵션**: 전투 배속/스킵, 애니메이션 속도 설정.
5. **접근성**: 색+아이콘 이중 표기, 텍스트 크기 옵션, 키/패드 지원.

## 7. 입력 매핑 (초안)

| 행동 | 마우스 | 키보드 | 패드 |
|------|--------|--------|------|
| 주사위 굴리기 | 버튼 클릭 | Space | A |
| 칸/대상 선택 | 클릭 | 방향키+Enter | D-Pad+A |
| 메뉴/취소 | 우클릭 | Esc | B |
| 인벤토리 | 아이콘 | I | Y |
| 배속/스킵 | 버튼 | Tab | RT |
