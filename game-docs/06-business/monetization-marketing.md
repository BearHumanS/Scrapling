## 1. 수익화 모델

- **기본: 유료 구매(Buy-to-Play / Premium).** 인디 보드 RPG에 가장 자연스럽고
  Pay-to-Win 논란이 없음(특히 멀티 도입 시 중요).
- **얼리 액세스(검토)**: EA 가격 → 1.0 시 가격 인상 전략(초기 매출 + 피드백).
- **확장 수익(후속, 선택)**:
  - 유료 DLC(추가 맵·클래스·캠페인) — 콘텐츠형, P2W 아님.
  - 코스메틱(말/보드 스킨) — 멀티 단계에서 검토, 게임플레이 영향 없음.
- **지양**: 확률형 BM, P2W, 강한 과금 유도(장르·평판과 충돌).

## 2. 가격 전략 (가안)

| 단계 | 가격 정책(예시) |
|------|----------------|
| 데모 | 무료 |
| 얼리 액세스 | 정식가 대비 할인된 진입가 |
| 정식 1.0 | 인디 보드/로그라이트 시장가 참고 확정 |
| 런치 | 출시 주간 소폭 할인(선택) |

> 구체 가격은 경쟁작·지역 가격(한국/글로벌) 분석 후 확정.

## 3. 마케팅 타임라인

```
[개발 초기] Steam 페이지 + 위시리스트 오픈(최우선)
   → SNS/디스코드 개설, 개발 일지(devlog) 시작
[수직 슬라이스] 트레일러 1차, 스크린샷, 인플루언서 사전 접촉
[MVP/데모] Steam Next Fest 데모, 스트리머/유튜버 키 배포
[EA/출시 전] 출시일 공지·카운트다운, 언론 보도자료(프레스킷)
[출시] 런치 트레일러, 디스카운트, 커뮤니티 라이브 대응
[출시 후] 업데이트 마케팅, 세일 참여, 멀티 업데이트 홍보
```

### 핵심 원칙
- **위시리스트가 곧 출시 성패** → 가능한 한 일찍, 꾸준히 누적.
- **도트 비주얼 + GIF/움짤**은 SNS 확산에 강함 → 짧은 클립 자산 적극 제작.

## 4. 커뮤니티

- **디스코드**: 피드백·테스터·열성 팬 허브.
- **Steam 커뮤니티/게시판**: 패치 노트·공지·버그 리포트.
- **개발 일지**: 투명한 개발 과정 공유로 신뢰·기대감 형성.
- **베타 테스터**: 클로즈드 → 오픈(특히 멀티 단계).

## 5. 프레스 / 인플루언서

- **프레스킷**: 로고·스크린샷·트레일러·팩트시트·연락처(presskit() 등 활용).
- **인플루언서**: 보드게임/로그라이트/인디 채널 타깃, 데모·키 배포.
- **페스티벌**: Steam Next Fest, 인디 전시/어워드 출품 검토.

## 6. 측정 (KPI 연계)

- 위시리스트 추이, 데모 전환율, 트레일러 조회/클릭, 리뷰 점수, 리텐션
  ([PRD KPI](../01-prd/PRD.md))를 단계별로 추적·보정.
