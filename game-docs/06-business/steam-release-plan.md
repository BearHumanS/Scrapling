# Steam 출시 계획 (Steam Release Plan)

> **상태:** 🟠 리뷰 · **버전:** v0.2 · **최종수정일:** 2026-06-30 · **작성자:** 비즈니스
>
> 관련: [roadmap](../05-production/roadmap.md) · [monetization-marketing](monetization-marketing.md)
>
> **v0.2 결정**: 얼리 액세스 채택 → 아래 "얼리 액세스" 단계가 출시 경로의 핵심.

---

## 1. Steamworks 셋업

- [ ] Steamworks 파트너 등록(법인/개인사업자, 세금/은행 정보)
- [ ] 앱 등록 비용(Steam Direct) 납부 → **App ID** 발급
- [ ] 게임 SDK 연동(GodotSteam): 실적·클라우드 세이브·(후속)멀티 로비
- [ ] 빌드 업로드 파이프라인(steamcmd) 구성, 브랜치(default/beta) 설정

## 2. 스토어 페이지

- [ ] 제목·짧은 설명·상세 설명(한/영)
- [ ] 카피·태그·장르·기능(싱글/멀티/실적/클라우드) 설정
- [ ] **비주얼 에셋**: 헤더 캡슐, 라이브러리 아트, 스크린샷(도트 강조),
      트레일러(움직이는 도트·전투 연출)
- [ ] 시스템 요구사항, 지원 언어(현지화 계획 반영)
- [ ] **위시리스트 오픈을 최대한 일찍**(개발 중 트래픽 누적이 출시 부스트)

## 3. 빌드 / 기술 체크

- [ ] Steam 빌드 업로드·다운로드 검증, depot 구성
- [ ] 클라우드 세이브 경로/충돌 처리
- [ ] 실적(Achievements) 정의·연동
- [ ] 컨트롤러 지원 표기(Steam Input)
- [ ] 멀티(후속): Steam 로비/릴레이 연동, 방화벽/NAT 테스트

## 4. 등급 / 법무

- [ ] 연령 등급(한국 GRAC 등급분류, 해외 IARC/ESRB/PEGI 해당 시)
- [ ] 약관·개인정보(크래시/분석 데이터 옵트인 시)
- [ ] 폰트·에셋·애드온 **라이선스** 확인(상업 사용 가능 여부)
- [ ] 상표/IP 검토(부루마블류와의 독자성 — [risk-register R12](../05-production/risk-register.md))

## 5. 출시 단계별 체크리스트

### 데모 / Next Fest (선택)
- [ ] 데모 빌드(코어 루프 체험), 데모 페이지
- [ ] Steam Next Fest 일정 신청·연동

### 얼리 액세스 (채택 확정)
- [ ] EA 콘텐츠 분량·로드맵 공개, EA 안내문(기간·계획·가격 정책)
- [ ] 피드백 수집 채널(디스코드·게시판)

### 정식 출시 1.0
- [ ] 출시일 확정·공지(2주+ 전 카운트다운)
- [ ] 런치 디스카운트 설정(선택)
- [ ] 패치 노트·릴리스 빌드 안정화
- [ ] 리뷰/버그 대응 핫픽스 체계

## 6. 출시 후

- [ ] 리뷰 모니터링·핫픽스, 도전과제/콘텐츠 업데이트
- [ ] 세일 이벤트 참여(시즌 세일), 번들 검토
- [ ] 멀티플레이 업데이트 마케팅([multiplayer-plan](../03-technical/multiplayer-plan.md))
