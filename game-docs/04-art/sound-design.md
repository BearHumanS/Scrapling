## 1. 사운드 방향

- **하이브리드 사운드**: 도트 비주얼과 어울리는 **칩튠(chiptune) 기반 + 오케스트라/
  어쿠스틱 레이어** 혼합. 평상시 경쾌·복고, 보스·위기에서 웅장·긴장.
- **정체성**: "주사위·보드"의 톡톡 튀는 효과음으로 게임 고유의 청각 시그니처 형성.

## 2. 음악(BGM) 트랙 리스트 (초안)

| ID | 용도 | 분위기 | 비고 |
|----|------|--------|------|
| `bgm_title` | 타이틀/메인 메뉴 | 경쾌·기대감 | 짧은 루프 |
| `bgm_board_normal` | 일반 보드 진행 | 밝고 가벼움 | 메인 테마 변주 |
| `bgm_board_tense` | 후반/위기 보드 | 긴장·몰입 | 동일 모티프 어두운 변주 |
| `bgm_battle_normal` | 일반 전투 | 활기·박진감 | |
| `bgm_battle_boss` | 보스 전투 | 웅장·긴장 | 페이즈 전환 시 고조 |
| `bgm_shop` | 상점 | 아늑·여유 | |
| `bgm_meta` | 메타 강화 화면 | 차분·성취감 | |
| `bgm_victory` / `bgm_defeat` | 결과 | 환호 / 아쉬움 | 짧은 스팅어 |

> **모티프 통일**: 메인 테마 모티프를 상황별로 변주(명랑↔긴장)해 일관성 확보.

## 3. 효과음(SFX) 리스트 (초안)

| 분류 | 예시 SFX |
|------|----------|
| 주사위 | 굴리기, 멈춤(눈 확정), 더블 효과음 |
| 보드/이동 | 말 한 칸 이동(스텝), 출발칸 통과 보너스, 순간이동 |
| 경제 | 골드 획득/지불, 땅 구매, 건물 건설/업그레이드 |
| 전투 | 일반 타격, 치명타, 스킬(화염/빙결/급습), 피격, 회복, 사망 |
| UI | 버튼 클릭/호버, 팝업 열기/닫기, 확인/취소, 오류 |
| 보상/연출 | 아이템 획득(희귀도별 톤), 레벨업, 퀘스트 완료, 보스 등장 |
| 상태이상 | 화상·중독·빙결·기절 진입/지속 |

> 희귀도별 보상음(일반→전설로 갈수록 화려)으로 도파민 피드백 강화.

## 4. 적응형/레이어드 오디오

- **보드 긴장도 전환**: 진행도·HP·보스 임박에 따라 `bgm_board_normal`↔`tense`
  크로스페이드 또는 레이어 추가.
- **전투 페이즈**: 보스 페이즈 전환 시 악기 레이어 추가로 고조.
- Godot Audio Bus + 트윈으로 볼륨/레이어 제어([tech-stack](../03-technical/tech-stack.md)).

## 5. 믹싱 / 기술 구현

- **버스 구조**: Master → Music / SFX / UI / Ambience(개별 볼륨 옵션 제공).
- **포맷**: BGM은 ogg(루프 포인트), SFX는 wav/ogg.
- **동시발음 관리**: 동일 SFX 폭주 방지(쿨다운·보이스 제한).
- **옵션**: 마스터/음악/효과음/UI 개별 볼륨 슬라이더, 음소거.

## 6. 에셋 컨벤션

- **네이밍**: `sfx_category_name_##`, `bgm_context_mood` (예: `sfx_dice_roll_01`).
- **폴더**: `assets/audio/{bgm,sfx,ui,ambience}`.
- **루프**: BGM 루프 구간 메타데이터 명시, 인트로+루프 분리 가능.

## 7. 제작 / 소싱 방식

- 옵션: 자체 제작 / 작곡 외주 / 라이선스 에셋(상업 사용 가능 확인 필수).
