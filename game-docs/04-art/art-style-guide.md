## 1. 비주얼 방향

- **도트(픽셀아트)** 기반, 따뜻하고 친근한 톤(부루마블의 친숙함 + RPG의 모험감).
- **톤 혼합(확정)**: 평상시 밝고 채도 높은 팔레트(명랑) ↔ 보스·위기 장면은
  어둡고 대비 강한 연출(긴장). 같은 픽셀 규격 안에서 조명·팔레트로 분위기 전환.
- 가독성 최우선: 보드/말/칸/UI가 한눈에 구분되도록.
- 일관성: 모든 에셋이 동일 픽셀 스케일·팔레트 규칙을 따른다.

## 2. 해상도 & 픽셀 스케일

- **베이스 해상도(예시안)**: 320×180 또는 384×216 (16:9).
- **정수 스케일링(Integer scaling)**: 1x→2x/3x/4x로 확대해 픽셀 선명도 유지.
- **픽셀 퍼 유닛(PPU)**: 프로젝트 전역 고정(예: 16px = 1타일).
- Godot 설정: `viewport` 스트레치 + 픽셀 스냅, 텍스처 필터 Nearest.

## 3. 그리드 & 스프라이트 규격

| 대상 | 권장 크기(예) |
|------|--------------|
| 보드 타일 | 32×32 또는 48×48 |
| 캐릭터/말 | 16×16 또는 32×32 |
| 적/몬스터 | 32×32 ~ 64×64(보스 큼) |
| 아이콘(아이템/스킬) | 16×16 또는 32×32 |
| UI 패널 | 9-slice 활용 |

> 정확한 값은 보드 가독성 테스트 후 확정.

## 4. 컬러 팔레트

- **제한 팔레트** 사용(예: 32~48색 통합 팔레트)로 통일감.
- 기능색 규칙: 희귀도(아이템 색), 상태이상(중독=초록/화상=주황 등), 플레이어 구분색.
- 색약 고려: 색 + 아이콘/형태로 이중 표현.

## 5. 애니메이션

- **프레임 규칙**: idle/walk/attack/hit 등 상태별 표준 프레임 수 정의.
- **연출 우선순위**: 주사위 굴림, 말 이동, 전투 타격, 보상 획득(타격감·만족감).
- 프레임레이트·이징 규칙 통일, 과한 모션블러 지양(픽셀 가독성).

## 6. UI / 폰트

- 도트 UI 테마(패널·버튼·툴팁) 일관 스타일.
- **폰트**: 도트 비트맵 폰트 우선. **단, 다국어(한글/영문/CJK) 가독성 확인 필수**
  → 한글 도트 폰트 라이선스/완성도 검토, 필요 시 본문은 가독 폰트 병용.

## 7. 에셋 컨벤션

- **네이밍**: `category_name_state_##` (예: `enemy_slime_idle_01`).
- **폴더**: `assets/art/{board,characters,enemies,items,ui,fx}`.
- **포맷**: PNG(무손실), 스프라이트시트 + Godot 임포트 설정 표준화.
- **소스 파일**: 원본(.aseprite 등) 별도 보관, 내보내기 규칙 문서화.

## 8. 사운드(연계 메모)

- 도트 비주얼과 어울리는 칩튠/오케스트라 하이브리드 등 방향은 별도 사운드 문서로
  확장 예정(현재 art 가이드 범위 밖).
