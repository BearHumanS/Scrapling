# 미사일 키우기 : 궤도 방어전

표창 키우기류의 **소환 → 합성 → 성장** 루프에, **타워 디펜스**를 붙인 브라우저 게임입니다.
빌드 도구나 외부 라이브러리 없이 순수 HTML/CSS/JavaScript 로만 만들어져 있습니다.

## 실행

```bash
# 파일을 직접 열어도 되고
open missile-rush/index.html

# 로컬 서버로 띄워도 됩니다
python -m http.server 8000
# → http://localhost:8000/missile-rush/
```

## 게임 루프

```
골드 → 소환 → 같은 등급끼리 합성 → 더 센 미사일 → 더 많은 격추 → 더 많은 골드
                     ↑                                              │
                     └──────────────── 업그레이드로 배율 강화 ───────────┘
```

1. **소환** — 빈 발사대를 누르거나 하단 `소환` 버튼으로 미사일을 뽑습니다. 소환할수록 비용이 6.5%씩 오릅니다.
2. **합성** — 같은 등급 미사일을 드래그해서 겹치면 한 단계 위 등급이 됩니다. 등급당 위력 약 2.3배, 장전 속도와 폭발 반경도 함께 좋아집니다. 다른 등급끼리 겹치면 자리만 교체됩니다.
3. **방어** — 발사대는 경로를 따라 진격하는 적에게 자동으로 유도 미사일을 쏩니다. 적이 기지에 닿으면 내구도가 깎이고, 0이 되면 게임 종료입니다.

## 시스템

| 요소 | 내용 |
| --- | --- |
| 미사일 등급 | 10단계 (폭죽탄 → 궤도 강습포). Lv3 이상부터 스플래시, Lv8 EMP 는 피격 대상 2초간 감속 |
| 발사대 | 4×3 격자, 처음엔 6칸 개방. 업그레이드로 12칸까지 확장 |
| 적 | 일반(원) / 고속(삼각, 체력↓ 속도↑) / 장갑(사각, 체력↑) / 보스(별, 10웨이브마다) |
| 조준 우선순위 | 선두 · 최강 · 근접 — 하단 `조준` 버튼으로 순환 |
| 스킬 | 궤도 폭격 — 전체 DPS의 3.5배를 화면의 모든 적에게 즉시 타격, 쿨타임 55초 |
| 업그레이드 | 탄두 위력 / 장전 속도 / 자금 회수 / 소환 등급 / 발사대 개방 / 기지 보강 |
| 편의 기능 | 자동 합성, 자동 소환, 1~3배속, 최고 웨이브 기록(localStorage) |

## 조작

- **클릭 / 탭** — 빈 발사대: 소환, 잠긴 발사대: 개방 구매
- **드래그 앤 드롭** — 미사일 합성 및 자리 이동 (마우스·터치 모두 지원, Pointer Events 기반)
- 상단 우측 `x1` 버튼으로 배속 전환

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 골격, 스탯 바, 컨트롤 버튼, 업그레이드 패널 |
| `styles.css` | 다크 밀리터리 테마. 캔버스는 `max-width`/`max-height` 로만 제한해 540:960 비율을 유지 |
| `game.js` | 게임 전체. 상태(`newGame`) → 갱신(`update`) → 렌더(`draw`) 단일 루프 |

`game.js` 는 540×960 논리 해상도를 기준으로 그리고, 클릭 좌표는
`getBoundingClientRect()` 로 역변환합니다. 캔버스 비율이 왜곡되면 좌표가 어긋나므로
CSS 에서 `object-fit` 대신 대체 요소의 고유 비율 유지 규칙을 이용합니다.

## 밸런스 상수

`game.js` 상단에서 바로 조정할 수 있습니다.

- `TIERS` — 등급별 위력 / 장전 시간 / 폭발 반경 / 탄속 / 색상
- `enemyHp(wave)` = `30 × 1.235^(wave-1)`, `enemyGold(wave)` = `4 × 1.155^(wave-1)`
- `summonCost()` = `25 × 1.065^소환횟수`, 업그레이드 비용은 레벨당 1.3~1.6배

## 앞으로 붙일 만한 것

- 웨이브 사이 배치 단계와 발사대별 사거리 (지금은 사거리 무제한 유도)
- 미사일 계열 분화(관통 / 도탄 / 지속 화염)와 시너지
- 영구 성장 재화가 남는 환생(프레스티지)
- 남은 기지 내구도 기반 웨이브 클리어 보너스, 리더보드
